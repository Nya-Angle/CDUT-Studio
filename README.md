## 📖 项目简介

> **CDUT Studio** 是一款深度适配**成都理工大学**学术科研与校园生活生态的全功能端侧 AI 智能体（Agent）客户端。

系统以 **Pi Coding Agent 为唯一执行内核**，彻底践行 **100% 本地优先（Local-First）** 架构。无论是优势学科的深度科学计算、期末复习精准提分带教、校园教务自动化速查，还是复杂的奖助学金与公文材料多栏比对审核，CDUT Studio 都能化身为成理师生的“端侧赛博外脑”，用前沿智能体自动化流打破重复劳动，重构高校学习与科研范式。

## 🏛️ CDUT 校园专区与教务特区

针对成理校园日常学习与教务查询需求量身定制，在安全合规边界内全面消除重复查课表、登录繁琐与事务填报负担：

<p align="center">
  <img src="assets/screenshots/cdut-campus-zone-preview.png" width="92%" alt="CDUT 专区主界面" />
</p>

### 1. 特区账户一键接入与安全保护
- **原生卡片式免跳转登录**：输入学工号完成统一身份认证，界面零白屏、零外部弹窗；
- **凭据硬件级加密存储**：账号信息由操作系统 `safeStorage`（DPAPI / Keychain）加密持久化于本地，绝不上报云端，后台自动维持安全会话；
- **真实身份卡片**：自动规整姓名、学工号、学院专业及学籍证件照，生成专属身份卡片。

### 2. 便捷教务服务
- **课表全景透视**：自动对齐北京时间教学周，清晰掌握当天及全周课程编排、上课教室与授课教师；
- **成绩与绩点精确折算**：完整支持百分制、五级制（优/良/中/及格/不及格）及两级制（合格/不合格）自动映射，多次考核同分自动聚合最新学期；
- **考场速查与空教室检索**：一键查询期末排考安排，按教学楼栋、时段智能检索自习空教室；
- **砚湖易办轻量辅助**：以自然语言对话引导表单信息流转，协助快速梳理请假申报理由。

## 📑 材料审核专区 V2

面向班级评优、奖助学金材料申报、项目申报等公文审校场景打造的工业级三栏审校工作台：

```
┌─────────────────────────┬─────────────────────────┬─────────────────────────┐
│ 📌 左栏：审核标准依据库  │ 📄 中栏：送审材料与槽位  │ ✅ 右栏：AI 研判与覆盖账本 │
├─────────────────────────┼─────────────────────────┼─────────────────────────┤
│ • 评奖细则与公文规范原文  │ • 必需材料槽门控 minCount│ • 11 节点确定性与网关协同 │
│ • 负责人规则文本编译器  │ • 槽位同名文件版本链追踪│ • 覆盖账本 CoverageLedger│
│ • 结构化规则解析与版本链 │ • PDF / Word / Excel 解析 │ • 初审/补件/申诉复核闭环 │
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

- **负责人规则文本编译器 (`compileOwnerRules`)**：直接粘贴通知公文，系统自动逐行提取条款、严重度括号与条目编号，编译为结构化标准规则；
- **材料槽门控与覆盖账本**：针对必须提交的材料槽位（如“成绩单”、“获奖证书”）进行严格数量校验，检查结果按分组规则逐项展开覆盖账本，无规则或未执行处如实标注；
- **争议解决全生命周期**：支持完整的「初审驳回 ➔ 补充材料 ➔ 再次复核 ➔ 维持原判/更正定稿」合规流转机制。

## 🎯 AI 速课堂与智联万站

### 1. AI 速课堂：期末极速提分带教

## 🧠 长期记忆与智能体底座

CDUT Studio 以 **Pi Coding Agent 为唯一执行内核**，在提供强大任务规划与工具调度的同时，最新引入了革命性的**长期记忆与反思网络（Long-Term Memory）**：

```
                    ┌── 异步反思提炼引擎 (Reflector: 认知偏好 / 习惯 / 纠错归纳)
Pi 智能体驱动底座 ──┼── 本地透明审计向量存储 (Auditor & Local RAG Store)
                    ├── 设置页全生命周期记忆管理面板 (查看 / 检索 / 编辑 / 删除)
                    ├── 三层 Context Sandwich 提示词安全沙盒 (静态 ➔ 系统 ➔ 用户)
                    └── 18 家主流模型协议原生适配 (DeepSeek / Gemini / Claude 等)
```

- **反思引擎自动提炼（Reflector）**：Agent 在执行多轮任务后，自动于后台对交互过程进行认知剖析，提炼出用户的编程习惯、科研偏好与纠错教训，实现“越用越懂你”；
- **本地审计与透明管理（Auditor & View）**：所有提炼的记忆条目完全以本地 JSON 存储并建立本地向量索引。用户可在「设置 → 长期记忆」中随时审查、全文检索、微调修改或一键清除，记忆资产 100% 掌握在自己手中；
- **增量检查点引擎**：毫秒级快照每一次文件修改，支持随时一键无损回滚，内置 MinGit 引擎保障零外部依赖开箱即用。

<a id="security-and-privacy"></a>

## 🛡️ 本地安全防线与离线公告体系

CDUT Studio 坚守**本地优先（Local-First）**与数据私有承诺，全链路装配五重防御保障：

- **硬件级凭据加密**：所有模型 API 密钥与特区账户凭据均由操作系统 `safeStorage`（DPAPI / Keychain）加密保存在本地 `~/.cdutai/` 目录，杜绝隐私外泄；
- **沙箱隔离与快照熔断**：无工作区会话自动置于安全沙箱，对用户主目录与驱动器根目录绝对拒止快照，物理复制附带 500 文件安全熔断；
- **离线安全公告体系（Bulletin）**：应用随安装包内置发布通告与安全通知，不发起任何新闻类外部轮询，保持系统透明、极简、无后门；
- **网络传输安全插页**：内置受管浏览器集成高危证书告警与交互式安全插页，全链路过滤 C0 控制字符与截断风险，守护校园网络交互安全。

| **分发打包** | **Electron Builder** 25.1.8 | 支持 Windows NSIS / 便携免安装版及跨平台打包 |

## ⚡ 快速上手

### 📋 环境要求
* **Bun** >= 1.2.5 (推荐 1.4.2+)
* **Git** (可选，Windows 客户端内置 MinGit 引擎)

### 🚀 安装与启动

1. **克隆仓库**
   ```bash
   git clone https://github.com/Nya-Angle/CDUT-Studio.git
   cd CDUT-Studio
   ```

2. **安装 Monorepo 依赖**
   ```bash
   bun install
   ```

3. **启动开发环境**
   ```bash
   bun run dev
   ```

4. **工程规范校验**
   ```bash
   bun run typecheck
   ```
