## 一、启动应用

```bash
cd /home/miku/Bot/CDUTStudio/cdut-studio-review-agent
```

## 二、准备模板与案卷（若我留下的配置还在，可跳过）

1. 展开「打开其他案卷 / 从已发布模板新建」
2. 选择模板 **实验室使用申请（S2）**（`a15-s4-lab@1`）
3. 填写：组织名称=地球物理学院、负责人=王老师、使用人数=**18**、
   使用日期=2026-11-10、使用时段=10:00-12:00、用途=课程实验
4. 案卷标题随意，点「创建一份案卷」

## 三、关键一步：导入原件（我无法自动化的唯一环节）

1. 在「材料槽」下拉里选 **实验室使用计划书**
2. 点下方虚线框「点击选择或拖入文件」
3. 在弹出的 **Open Files** 对话框里选 `work/e2e/manual-kit/lab-18-complete.docx`
4. 点 **Open**

**预期**：界面出现「登记中…」后显示该文件，`state.v2.json` 的 `documents` 非空。
