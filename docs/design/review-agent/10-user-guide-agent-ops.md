# 使用指南：让 AI Agent 帮你处理审核案卷

> 写给没有技术背景的使用者。跟着步骤做就行，不需要懂任何代码。
> 适用于 CDUT Studio（Profer）桌面版的「材料审核智能体」功能。

---

## 这个功能是什么？

简单说：**你可以把审核案卷的杂活交给 AI 助手做**。

以前你要自己一步步操作：新建案卷 → 上传材料 → 提交 → 点开始审核 → 等结果 → 导出报告。现在你可以「指派」AI 助手替你做这些，你只需要在关键节点看一眼结果。

**但有一件事 AI 永远不能偷偷做**：正式的审核决定（比如「通过」「驳回」）。默认情况下，这类决定必须由人来做。如果你明确愿意承担这个责任，可以在设置里打开「AI 代批」开关（怎么开、有什么风险，见下面第 5 节）。

---

## 开始之前：你需要准备什么

1. **一个已发布模板**（审核规则）。如果你还没建过模板，先看第 3 节的「前提」。
2. **材料文件**（PDF、图片等）放在电脑里，比如桌面上。
3. 就这些。

---

## 先搞懂两个词：审核依据 vs 审核材料

这是整个审核页面最重要的一组概念，分清了就不乱：

| | 审核依据（判定标准） | 审核材料（被审的东西） |
|---|---|---|
| **是什么** | 评分细则、管理办法、评选条件这类「规则文件」 | 学生申报表、获奖证书、票据这类「要被检查的材料」 |
| **谁提供** | **人**——管理员上传或录入规则 | 申请人交的，由你或 Agent 登记进案卷 |
| **AI 拿它干嘛** | 当**尺子**：AI 拿着规则去比对材料 | 当**考卷**：AI 一份一份读，对照规则判断符不符合 |
| **在界面上** | 预审工作台**左栏**「审核依据」 | 预审工作台**中栏** + V2 案卷的材料列表 |

一句话：**依据是人定的，材料是 AI 看的**。AI 自己不会发明标准，它引用的每条判断都能追到依据材料里的原文。

---

## 界面四个分栏分别是什么

审核页面顶部的四个标签，按使用频率排：

1. **预审工作台**——日常看结果的地方。三栏布局：左栏审核依据、中栏待审条目和证明、右栏 AI 问题卡。适合「人工逐条过」。
2. **V2 案卷**——结构化的案卷管理（模板字段、材料槽、阶段任务、Agent 指派都在这）。适合「按流程走」和「把活交给 Agent」。
3. **模板编排**——管理员用：定义审核模板（字段、材料槽、规则、阶段流程）。做好一次，后面反复用。
4. **批次管理**——**批量审核**入口。把几十上百个案卷绑成一个批次，锁定同一版本的模板和规则，排队自动逐个审核；表格看每个案卷的进度，可以暂停/继续/重试失败的，单个案卷出问题不会卡住整批。

> 目前批次管理处于基础可用状态：创建批次、锁定模板版本、跑队列。如果你要做大规模批量审核，先从一个批次 10 个案卷试起。

## 1. 第一步：把案卷「交给 Agent」

1. 打开 CDUT Studio，左侧点 **「CDUT 专区」**，再点 **「V2 案卷」**。
2. 打开你要处理的案卷（或按后面第 3 节新建）。
3. 在案卷页面往下滚，找到一个叫 **「Agent 指派（显式授权）」** 的卡片。
4. 点右边的 **「交给 Agent」** 按钮。

点完之后你会看到：
- 卡片里多出一行，形如 `asg-xxxxxxxx · 有效 · 8 项动作 · reviewer`
- 按钮变成「已有 1 个有效指派」（灰色，不能重复点）

**这是什么意思？** 你刚才给了 AI 一张「工作许可证」，允许它对这个案卷做这些事：查询、建案、登记材料、提交、发起审核、查进度、取消、导出报告。**不包含**「通过/驳回」这类审核决定。

### 想收回许可证？

随时点该行右边的 **「撤销」**。撤销后 AI 立刻不能再做任何新操作（已经做完的会保留在案卷时间线里，不会消失）。

---

## 2. 第二步：让 Agent 干活

打开一个 **Agent 会话**（左侧栏「Agent 会话」→ 新会话），像聊天一样跟它说需求：

| 你说 | Agent 会做什么 |
|---|---|
| 「帮我看看有哪些审核模板」 | 列出可用模板、字段、需要的材料 |
| 「帮这个案卷跑一次审核，完了告诉我结果」 | 发起审核 → 自动等结果 → 给你检查摘要和结论 |
| 「把桌面上那份证明图登记到案卷里再审核」 | 登记（要求文件在授权目录内）→ 提交 → 审核 |
| 「导出这个案卷的审核报告」 | 生成报告文件，告诉你文件在哪 |

**Agent 会先问你或自己查**，然后一步步执行，每一步都会告诉你做到哪了。

### Agent 怎么知道案卷信息的？

它**不能直接翻你的数据库**，但它有一套查询工具（查模板、查案卷列表、查案卷详情、查审核进度），可以自由决定什么时候调、调哪个——就像一个有权限查系统的助理。

不过有三条硬约束：

1. **看不到材料原文**：Agent 拿到的永远是摘要（文件名、检查结果、结论），材料原文要看你自己在页面上点开核对。这是防止材料里的内容被当成指令的安全设计。
2. **写操作必须有指派**：查询类工具随便用；但凡要「改东西」（建案/登记/提交/发起审核），它会先检查你有没有点过「交给 Agent」，没有就直接拒绝并告诉你。
3. **决定类还要多一道锁**：即使你指派了，做「通过/驳回」类决定还要求你开过 AI 代批开关（第 5 节），否则系统层面直接拒绝，Agent 也会如实告诉你被拒了。

> 顺便说明：审核页面**右侧的问答抽屉**不是这个 Agent——它是内置的审核助手，只会根据你当前选中的问题卡和案卷信息回答问题，不能操作任何东西。能干活的 Agent 在左侧「Agent 会话」入口。

几个你可能会遇到的提示，都是正常保护，不是故障：

- **「指派不存在 / 请先指派」**：说明你还没点「交给 Agent」，或者会话对不上。回到案卷页面重新指派一次。
- **「文件路径不在授权目录内」**：Agent 只能用你授权过的目录里的文件。把文件移到会话工作区/已附加目录里再试。
- **「请先在材料槽下拉中选择槽位」**：登记材料前要先告诉系统这份材料归到哪个槽（比如「主要材料」）。槽位下拉在材料列表上方。

### 材料怎么导入：虚线框，点击或拖入都行

V2 案卷的材料列表上方有一个**虚线框**：

- **点击它**：弹出系统文件选择窗，可以按住 Ctrl 多选
- **直接把文件从文件管理器拖进虚线框**：松手就登记，支持一次拖多个

登记成功的材料立刻出现在下方列表里（带版本号）。如果模板定义了材料槽，先在槽位下拉选好目的地再导入。
- **「AI 代批未开启」**：你让它做「通过/驳回」这类决定了，但代批开关没开。要么你自己去案卷页面点「阶段通过」，要么看第 5 节。

## 3. 从零建一个新案卷（也可以全程交给 Agent）

**前提**：需要先有已发布的审核模板。如果你还没有：V2 案卷页面上方的「从已发布模板建案」旁边有模板管理入口；或者直接用现有的「学生综合素质测评」演示模板。

两种方式建案卷：

- **自己点**：V2 案卷 → 选择模板 → 填字段 → 创建 → 登记材料 → 提交。
- **让 Agent 来**：先点「交给 Agent」，然后对 Agent 说「用学生综合素质测评模板给张旅程建个案卷，登记好材料后提交」。

不管谁做的，结果一样：案卷状态变成「已提交」，审核任务自动创建。

---

## 4. 看结果：案卷时间线

案卷页面最下方的 **「案卷时间线」** 是这个案卷的完整历史记录，每一条都标了是谁做的：

- 🔵 **人工** —— 你自己点的操作
- 🟣 **AI Agent** —— Agent 替你做的操作
- ⚪ **未记录** —— 早期旧数据（升级前产生的），如实标注

顶部有筛选按钮（全部 / AI Agent / 人工），想只看 AI 做了什么就点「AI Agent」。

**建议养成习惯**：Agent 干完活后，来时间线扫一眼，确认它做了哪些操作。

## 5. AI 代批（谨慎使用，默认关闭）

### 这是什么

打开后，被你指派的 Agent 就可以**替你做审核决定**：阶段通过、退回补件、最终驳回、补件判定（满足/不足）。

### 怎么开

1. 案卷页面 → 「Agent 指派（显式授权）」卡片。
2. 点 **「▸ 高级」** 展开（默认收起，这个开关故意放在不显眼的地方）。
3. 点 **「关闭」** 按钮旁边的确认框 → 弹出风险提示。
4. 认真读完提示，确认能接受 → 点 **「我已知晓风险，确认开启」**。

### 开之前必须知道的三件事

1. **责任是你的**。AI 代你做的每个决定都会记入案卷时间线（标紫色「AI Agent」），但决定的责任在使用这个功能的你。
2. **两道锁都要开**。除了这个开关，你还必须在指派时授权「决定类动作」——只有指派和开关同时允许，Agent 才能做决定。任何一个不满足，它都会被系统直接拒绝。
3. **有些决定 AI 永远做不了**。模板里指定了终审角色（比如老师终审、评委打分）的环节，不管开关开不开，Agent 都过不去，必须由相应的人来做。

### 随时可以关

同一位置再点一次 → 「确认关闭」。关闭后 Agent 立刻不能做任何新决定（已经做了的保留在时间线）。

系统也会记录：这个开关是谁、什么时候开的。Agent 自己**永远无法**打开这个开关。

## 6. 常见问题

**Q：AI 审核说「材料中未见证书」，但我明明传了？**
先确认：材料是不是登记到正确的材料槽了？是不是图片格式（图片走 OCR 识别，扫描件质量太差会认不出）？可以在案卷页面的材料列表确认文件在不在。

**Q：Agent 说「审核运行失败：模型限流」？**
免费模型渠道有并发限制，系统会自动重试三次。还是失败就等一两分钟再让它重跑。

**Q：我关掉了 Agent 会话，指派还在吗？**
会话停止时系统会自动撤销该会话的指派（时间线里能看到撤销记录）。想继续用就重新指派。

**Q：导出的报告在哪里？**
Agent 会告诉你具体路径，也可以在案卷页面的审核运行区点「导出报告」。文件在案卷的 `reports` 文件夹里（应用数据目录下），用任何 Markdown/文本工具都能打开。

**Q：我想让 Agent 每天自动处理新案卷？**
目前不支持。这是有意设计：每次都由你明确指派，AI 不会在后台自动接单。

## 7. 一页速查

```
交给 Agent：案卷页 → Agent 指派卡 → 交给 Agent
撤销指派：  同一张卡 → 撤销（Agent 立刻失去权限）
看它做了啥：案卷时间线 → 可按「AI Agent」筛选
让 AI 代批：高级折叠区 → 开关 → 读风险提示 → 确认
（默认关，两道锁：开关 + 指派含决定类动作）
出问题先看：时间线 + Agent 会话里的错误说明（都是中文人话）
```
