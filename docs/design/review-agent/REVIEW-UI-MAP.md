## 0. 进入路径

```
应用主界面
└── 左侧导航「CDUT 专区」
    └── 专区首页（特别账户 / 校园卡片区）
        ├── 「连接内网统一身份认证」        → 登录卡片

        ├── 「AI 速课堂」                    → 另一子页面
        └── 「智联万站」                     → 另一子页面
```

材料审核是 CDUT 专区下的一个子页面；进入后左侧应用导航栏仍在，审核内部用自己的二级导航切页。

## 1. 材料审核的二级导航（一级分节）

导航条在页面顶部，从左到右：**导入材料 · 当前审核 · 结果与办理 · 审核模板 · 批次管理 · 待办**

| 导航文字 | 内部标识 | 实际渲染的内容 | 说明 |
|---|---|---|---|
| 导入材料 | `workbench` | 有案卷：三栏工作台（审核依据 / 申报与证明 / AI 审核员或待我处理）<br>无案卷：一页式接入（`ReviewV3QuickIntake`） | **同一个导航项有两种形态** |
| 当前审核 | `local-candidates` | 候选方案与技术试跑工作台 | 名字叫"当前审核"，内容是候选/技术试跑 |
| 结果与办理 | `case-v2` | 案卷办理面板（`V2CasePanel`） | 点它会先异步读案卷聚合再切页 |
| 审核模板 | `templates` | 模板库与业务配置（`TemplateWizardPanel`） | 与"候选方案"共用一个二级导航条 |
| 批次管理 | `batches` | 批次面板（`BatchPanel`），含评委工作台（`ReviewV3T07Workbench`） | |
| 待办 | — | 不切页，只把三栏的**右栏**切到「AI 审核员/待我处理」 | 导航里混入了一个"切栏"动作 |

**二级导航（只在"审核模板/候选方案"两节出现）**：模板库与业务配置 ｜ 候选方案与技术试跑 ｜ 发布 50 套演示模板

## 2. 各分节内部结构

### 2.1 导入材料（无案卷时）

一页式接入，只有一个动作区：拖文件 / 选文件 / 从模板新建审核任务。

拿到案卷后**自动跳到"当前审核"**，不再停留在这里。

### 2.2 导入材料（有案卷时）——三栏

| 栏 | 内容 | 主要按钮 |
|---|---|---|
| 左「审核依据」 | 依据文件列表、手写依据、规则摘要 | 添加依据、上传依据 |
| 中「申报与证明」 | 申报材料、申报事项、证明材料、V3 证明归属 | 添加申报材料、添加证明材料、添加事项 |
| 右「AI 审核员 / 待我处理」 | 检查结果、待办任务、阶段决定入口 | 开始审核、前往处理 |

窄屏（<1100px）时三栏降级为单栏 + 顶部「依据 / 申请与证明 / AI 审核员」切换。

### 2.3 当前审核（候选方案与技术试跑）

工作台内部还有 5 个步骤标签：**1 原件 · 2 匹配 · 3 Check · 4 来源缺口 · 5 作者候选**

| 步骤 | 内容 | 关键动作 |
|---|---|---|
| 1 原件 | 本机原生案卷、材料清单 | 创建原生案卷、导入原件 |
| 2 匹配 | 50 套 D4 内容路由建议、公共兜底、模板选择 | 按建议确认模板 |
| 3 Check | 该模板固定下来的检查项 | 生成 / 查看技术计划 |
| 4 来源缺口 | 身份、归属、来源未确认项 | 逐项确认 |
| 5 作者候选 | B1 作者文档编辑 | 保存修订、预览、冻结候选、转可编辑业务模板草稿 |

### 2.4 结果与办理（案卷办理面板）

顶部：模板选择 / 创建案卷 / 已保存案卷列表（打开、删除）
中部：案卷字段、材料槽、申报事项表
下部：按模板规则检查、提交案卷、阶段决定（初审通过 / 退回补件 / 驳回）、导出报告

嵌在这里的子面板：
- 材料登记与原件校验
- 事实工作台（T03）
- 材料覆盖（T02）
- 规则检查结果（`ReviewV3TemplateRuleRun`）
- 阶段与决定（`ReviewV3T05HumanWorkflow`）
- 申诉历史（`ReviewV3F13AppealHistory`）
- 离线往返（`ReviewV3T09OfflineSection`）
- 报告面板（`ReviewV3T08ReportPanel`）

### 2.5 审核模板

模板库列表 + 模板编辑器（字段、分项、判据、材料槽、阶段、输出）+ 示例包。
包含：新建空白模板、创建可编辑示例草稿、导入模板配置、提取明确要求、使用已授权模型起草、发布。

### 2.6 批次管理

批次列表 + 新建批次；选中批次后进入评委工作台（评分轮次、分配、评分、排名、定稿）。

### 2.7 待办（右栏）

显示当前案卷的开放任务，点任务进入阶段处理。

## 3. 跨页跳转（现在会发生什么）

```
专区首页 ──进入本地材料审核──▶ 导入材料(无案卷)
                                  │ 拖入/建案
                                  ▼
                             当前审核(候选方案)   ←─ quickStart 强制跳这里
                                  │ 5 步走完、冻结计划
                                  ▼
                             结果与办理(案卷办理)   ←─ openBusinessCase 读聚合后跳这里
                                  │ 检查 / 提交 / 决定 / 申诉
                                  ▼
                               导出报告(弹层/文件)
```

其它跳转：
- 「待办」→ 不换页，只切右栏
- 「审核模板」⇄「候选方案」→ 二级导航互切（不离开模板类分节）
- 「发布 50 套演示模板」→ 停留原页，只弹 toast
- 「页面上的『前往处理』」→ 切到右栏任务列表
- 批次管理 → 选批次 → 同页下方出现评委工作台
- 导出报告 → 顶部按钮直接导出；案卷办理面板里还有一个「查看与导出本案审核报告」

## 4. 现状里容易让人迷路的地方（供你决定怎么改）

1. **导航名与内容不一致**：「当前审核」打开的是候选/技术试跑工作台；「结果与办理」打开的是案卷办理面板。
2. **「导入材料」一个导航项两种形态**：有没有案卷决定看到的是一页式还是三栏，用户无法预期。
3. **「待办」是个假导航项**：它在同一行导航里，但实际只切右栏，不换页。
4. **模板相关有两个入口**：「审核模板」和「当前审核」都在模板类分节下，但要先切到其中一节才看得到对方的按钮。
5. **导出报告有两个入口**：顶部按钮与案卷办理面板内按钮，行为不同（前者按当前案卷，后者在业务聚合视图）。
6. **建案入口分散在至少三处**：一页式接入、案卷办理面板的"从模板新建"、候选工作台的"创建原生案卷"，三者创建的是**不同类型的案卷**（V2 模板案卷 vs 原生工作区案卷）。
7. **候选 5 步与三栏工作台是两套心智模型**：前者按"原件→匹配→检查→缺口→作者"线性走，后者按"依据/申报/审核"三栏并行。
