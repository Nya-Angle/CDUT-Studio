## 2. 数据与行为合同

- `reportKind = preliminary | supplement-needed | decided | historical`。有效的当前最终决定才可归为 `decided`；存在活动补件时优先标 `supplement-needed`；过期/旧 Run 标 `historical`。
- `decided` 是**本地形成最终决定的报告状态**，不是学校认证/数字签章。所有导出仍是本机只读副本，不能宣称外部收件。
- 新投影包含 `reportKind`，并计入 `projectionHash/snapshotHash`；旧快照缺少此字段时保持原算法兼容，不得自动重写历史档案。
- `amendedByDecisionIds`、`noLongerCurrent` 只作为查询时的外部状态提示，不修改当时签发的报告内容。
- 本机保存记录放在每份归档的 `local-save-records/`，每次独立文件原子创建；状态 `saved/cancelled/failed`。此记录仅描述本机文件操作，不等于 F13 申诉送达、SchoolPort 回执或组织者签收。
- 未归档的历史 Run 无从重建当时完整标题/重命名/解析后的原件信息；明确记录“未知/未复核”，不凭当前状态推断历史。
