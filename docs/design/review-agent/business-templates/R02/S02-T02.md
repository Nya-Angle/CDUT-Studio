### 00.2 本轮已证实与未证实

## 01 唯一审核目的、申请人和负责机构

### 01.1 对象与决定边界

本模板的**预审对象**是“申请人对明确的课程/考试科目、考试批次，主张免考或特别考试条件时，政策入口、申请资格与证明事实是否成立”。每份案卷必须保留所依据的考试体系，至少区分：

- **省级高等教育自学考试课程免试**：实质是满足省自考规则后对指定课程办理免试，可能影响自考成绩/毕业条件；政策主体为四川省教育考试院，成都理工大学作为主考学校参与咨询或相应程序。不能把它改写为校内普通本科“免修”。`SRC-005, SRC-008, SRC-009`。
- **校内课程考试特殊安排**：须先确认课程考核制度、课程归口、具体考次、申请的安排类型。`SRC-002` 仅证明个别课程考试时长可以按程序获准不同于一般时长；**不证明学生个人免考或辅助器具、单独考场、延长考试时间已经有统一校本授权**。
- **国家教育考试的合理便利**：按考试主办机构、当年报考点要求和国家规定办理。四川2027研考**省级申办框架已核**：报名成功后向真实报考点申请、有关部门评估、获准后发告知书；成都理工5108**本点专门材料和签署角色**仍待核。`SRC-016/017`；高考规则`SRC-010/018`不得直接设为研考设备或延时门槛。

本模板最多形成 `PASS_FACT` 等**事实预审结果**，并向相应责任机构提交材料、冲突与待办；**最终批准、拒绝、记录豁免成绩、变更考试安排或正式复核**均为外部有权机构的动作。

### 02.2 硬排除：决定目的不同

1. **课程替代、免修与成绩替换**：来自英语等级成绩、已修学分等形成课程替代/免修；已有《课程替代及免修申请表》与审批/备案链，属邻接 S02 课程/学分事项，不能把它叫“免考已批准”。`SRC-001, SRC-003, SRC-004, SRC-006`。
2. **缓考、另约考试时间、补考、重修**：改变参加考试时间或考试机会，而非本模板的免考或考试便利。依 `S02-T01`（缓考及考试时间例外安排申请审核）范围路由；普通本科原文关于缓考申请、学院批准、教务系统登记可作路由证据（`SRC-001, SRC-002`）。
3. **体测免测/体育保健课**：体测免测的“体适能 APP → 校医院证明 → 管理员确认”与课程体育保健课替代有独立事实及归口；不因健康证明同时出现就套用本模板。`SRC-001, SRC-013`。涉及 G50 或相邻模板编号必须读 R02 总账后确定。
4. **研究生推免/成人教育免试入学/博士招生免试**：为招生资格与录取机制，不是本 ID 的课程考核免考。不得借“免试”同字纳入。
5. **教师更改成绩、学生成绩复核、学分认定**：教师成绩更正需原始试卷/成绩册及有权审核，学生复核仅启动复核；本 ID 不写成绩、不造新 Run 结果或学分。`SRC-001, SRC-002`。
6. **个别课程因考核大纲规定笔试/机试/口试**：正常教学评价方式本身不是个体“特殊考试条件申请”。`SRC-002`。

### 03.3 阶段、先后证明与跨批次约束

1. **申请材料与后续证明严格分开。** `M021` 是研考报名/考点定位材料，不是批准函；`M023` 是正式决定，`M024` 是实际落实，`M025` 是系统受理回执，`M026` 是退回通知，`M028` 是复核结论。后五项随事件产生，全部不得设为 L1 申请初始必交。
2. **省自考先行核验**：A07 信息变更、A08 学历无法验证，须先经真实考试机构/主考学校人工核实后再申报；不能以补件时虚拟填报“人工已通过”。`SRC-009`。
3. **学段与身份**：同一人可能同时是 CDUT 普通本科生和四川自考考生，应以 `F002` 考试制度和 `F010` 自考准考证确定 A 分支，不以大学 `F004` 一次性跨所有考试授权；来华留学生、硕士研究生课程、国家研考报名者各有不同边界。
4. **期限**：目前唯一精确当期窗口是已结束的 `SRC-009` 2026 秋省自考免试；无现行次轮公告时 `F018=POLICY_UNCONFIRMED`。非自考校本考试期限和撤/复核程序均不得凭惯例设定。
5. **考试批次之外无“资金批次”**。无需加入资助/报销字段。费用 `SRC-009` 8 元/科是其**2026 秋公告**的申报环节信息，非审查资格条件，是否需要收据不得从该信息反推。

4. **GAP-05显著收敛**：`SRC-016/017`使2027四川研考省级申办入口、报名后申请、评估与告知书**有当前证据**；与2026“网上确认阶段办理”形成重大版本冲突，2027已取消独立网上确认。`SRC-007`仅用作历史比较。仍待成都理工5108点2027专项细则、便利提交截止及实际签发账号，不得因省级入口已核而自动批措施。
5. **GAP-01/02没有伪造闭环**：检教务处管理制度和2026考务公告，并从学校PDF取得`SRC-015`缓考边界；学籍公开栏目仍列2019制度而另有学院较新汇编引用，未取得正式废止/修订对照。未发现普通本科个人免于考试保学分、个人额外延时或单独考室完整审批规程，均维持`OFFICIAL_POLICY_UNVERIFIED`。
6. **GAP-04最小披露**：`SRC-018`支持高考中由专业人员评估而非OCR自判；`SRC-019`约束敏感健康信息处理；`SRC-020`说明高考身份证复印件证明事项曾被取消。上述规则不直接给CDUT课程设诊断阈值，**高考、研考、普通本科分开受理和限权**。

## 05 角色、权限与可信数据边界

### 05.1 身份、事实、决定三层不混写

| 层次 | 输入可信源 | 可用动作 | 禁止的捷径 |
| --- | --- | --- | --- |
| 申请事实 | 申请人上传材料、本人陈述、表单字段；均标**待核** | 生成待核事项、材料版本、需要的权威回执清单 | 不把上传人填的“考籍有效”“残疾类别”“院领导已批准”作为事实 |
| 校内已认证事实 | 学校认证会话、正式学籍/选课/考务源、学校工作人员在授权业务系统中的校验意见 | 只按数据所属系统核对学生身份、课程、考次和有权签署记录 | 不用前端 `studentId`、`teacherRole`、院系名称或自由文本推定权限 |
| 省级/国家考试事实 | 省自考管理系统、学信网/中国教育考试网核验、省级招考机构/考点书面结果 | 校验考籍、证书、免试状态、合理便利结果及其考次 | 不把主考学校咨询电话或历史公告转换为当前决定权限 |
| 医疗/残疾相关证据 | 有权签发证明及核验机构；校医院等角色**只有政策授权时**才参与 | 保留必要诊断/功能需求、发行与核验状态，送人工必要性审查 | 不由 AI 判定残疾等级、医学必要性或不适当公开敏感诊断全文 |
| 正式决定 | 有权主体经认证的业务决定、批准单、结果告知书及版本/签章 | 留存决定及执行绑定；仅在签署与授权均核实后标“决定已收到” | 不以预审 `PASS_FACT`、模型总结或 Renderer 按钮自动生成获批状态 |

### 05.2 角色职责约束

1. **申请人/可能的代理人**：仅对自身材料真实性承担提交义务。代理权限、监护或委托证明制度待核，系统不能默认老师可以代学生申请。
2. **学院、系部、任课教师**：课程组织、日常成绩、部分课程替代或缓考在校本原文中各有职责；**不能跨授权主体处理省自考课程免试或国家教育考试考点便利**。`SRC-001, SRC-002, SRC-003`。
3. **教务处**：与普通本科课程考核组织、学籍/成绩管理相关；其岗位权限必须逐事项确认。不能凭技术侧“Main teacher”身份默认有全部审核权。`SRC-001, SRC-002`。
4. **继续教育学院/主考学校**：可作为省自考的咨询与部分异常核验入口；2026 秋原始流程图将**主考学校或市州**列为二级审核、**省考试院**列为三级审核。必须由省系统考籍归属与认证岗位识别具体负责本人的二级审核者；CDUT 在咨询电话名单内不等于本人的二级处理人，更不等于三级终审者（`SRC-009`）。
5. **研究生院/报考点**：`SRC-016/017`确认2027省级申请入口与告知书，但不代表成都理工5108对所有四川考生有权；由真实报名点归属决定送其实际有权机构，点位详细材料与签署权限仍待证。2026旧网上确认流程不得沿用到2027；这不同于校内研究生课程考试。
6. **人工决策者/复核人**：按所属考试制度在真实身份系统校验角色、组织、有效期限、案卷范围及本人利益冲突；复核人是否要求回避原决定人等未核条款只标待研。

### 05.3 系统接线的拟定可信边界（技术约束，不宣称源码已支持）

- Renderer/上传文件/模型提取出的 `actor`、学校机构名、决定意见均是**不可信输入**。应由 Main/宿主可信认证源绑定 `actorId`、机构、实际岗位授权和一次操作的案卷目标，记录操作时间、结果版本、签名或授权凭据。Preload/IPC 仅传请求，不授予权力。
- 决定与原件必须关联**考生/案卷 ID＋考试制度＋年度批次＋目标课程/科目＋源材料版本**，避免将一个考次的授权重用到下一考次。后续拟与 V3 Case/Run/Decision 主权模型对齐，不制造旧 `run@rev` 冒充真实 Run。
- 敏感身份与健康数据最小化：根据`SRC-019`先确认合法处理依据、必要性、告知及权限，只暴露本次核验必要摘要和结果；P3原始诊断限授权核验者访问，留痕不复述病史。`SRC-018`高考专家评估不能变成本科/研考模型医学判断，`SRC-020`提醒不同考试材料要求不可混用。
- 不得因证据缺失直接作行政驳回：需要区分缺材料、材料不可读、权威源不可达、政策待确认、事实冲突和必须人工裁量；后续状态至少保留 `PASS_FACT`、`NOT_APPLICABLE`、`NEEDS_MATERIAL`、`CONFLICT`、`UNREADABLE`、`SOURCE_UNAVAILABLE`、`POLICY_UNCONFIRMED`、`NEEDS_HUMAN_DECISION`。
- 正式审批/撤回/复核的生效时间须以主管系统签发/送达时间为准，不能用 UI 本地点击或 AI 生成时间替代。

### 05.5 跨来源读取与证明优先序

1. 学生声明及截图只证明“有人如此主张”；已核真实性的签发机关证件/盖章档案高于自行编辑文本；有权业务系统**当前状态**高于历史个人导出的状态截图。若源被暂时阻断，使用 `SOURCE_UNAVAILABLE`，而不是默认截图为真。
2. 由省自考系统、学信网、中国教育考试网、校内学籍/选课/考务或正式纸质档案读取数据，须先核该途径可合法访问；**本草稿不声称这些接口已接通**。人工通过官方查询/盖章档案确认也可留可审计来源；省公告明确仍要求考生在其官方系统按类别提交的原件，不因我们的本地记录而免除省要求。
3. 复用 `M029` 的 G50/S/T 权威结果只限**相同人、同一制度、相同考次或明确跨期有效范围、同一目标、未撤销的已签决定**。非本模板权责的成绩替代、学分免修、缓考、体测免测，即便真实也只能作邻接路由凭据，不产生 S02-T02 免试/合理便利效果。
4. 提取值与决策对象采用不可混同的引用：`caseId / regime / batch / applicantAuthorityKey / targetCourseOrExam / evidenceVersion / signerAuthority`；对同一材料标“所声称人”“已核归属人”“原始签发人”三层。跨科目、跨考试体系复用必须显式逐目标授权。

### 05.6 材料版本、撤销与敏感信息

- 每件 `M` 应保存 `sourceId`、`originator`、`holder`、`subjectKey`、`targetRefs`、`issuedAt`、`receivedAt`、`contentHash`、`version`、`supersedes`、`verificationAt`、`verifiedByAuthority`、`visibility`；其中未知字段可空但不可伪造。
- 取代附件后，旧附件及其已通过事实结论改为“历史/待重新验证”；仅重核依赖该附件或其变更字段的项，其他未受影响材料不必全案重做。**人工正式决定不由模型自动撤销**，若基础事实已变化，应交原有权机关决定是否更正或停止执行。
- `F006/F036/F038/F039` 等实名/健康信息以强隐私权限管理。对于复核、申诉，普通查看者只应见“证明有效待核/已核”及必要业务摘要；不在跨 G/S/T 路由中复制完整病史。

### 06.3 字段触发与不变量

1. `F002` 决定业务根域：A 类必须能确认为四川自考考籍，B 类需校内课程，C 类需国家考试报考点；D/X 情形只路由/事件，不创造另一种正式批准。`F004` 对不同制度可能是不同官方身份键，必须有可追溯关联而非强行等同。
2. `F014/F015` 逐目标核对；一张证书申请数门课程时生成多个 `Target`，共享原件版本却要分别计算学分/名称映射、累计免试门数和结果。每个目标结果不因同批另一个目标通过而自动通过。
3. `F017` 本地收到申请的时间与省系统正式提交时间分列，不得用本地时间验证 `SRC-009` 的截止。`F018` 当前性未知应阻断**自动资格终判**，但不阻止归档已有历史案例。
4. `F042` 和 `F048` 属后续事件，不得从 `F016` 的申请意愿填值；`F041` 每一次正式操作均应按真实组织权限重新核验。`F044` 变动会令依赖该证据的事实预审失效，不在未核验时复用旧结论。

## 07 材料槽与证据目的

### 07.1 材料槽时间性与存储规则

- **`M001`—`M031` 共 31 槽，连续不复用。**“当前”是已经识别出对应制度/办理情形且正在准备 L1 申请时；“条件”只在表中触发条件为真时要求；“后续”仅相关阶段实际发生后产生。公开制度、权威系统读取结果、案卷台账也属于证据槽，**不等于要求申请人上传纸质文件**。
- 权威替代分为两层：**本地事实预审**可使用有合法权限取得的同一源系统可信记录免去重复上传；**向省考试系统正式申报**仍服从 `SRC-009` 对该类别身份证件、证书、成绩档案等原件的要求，本模板不能擅自改省平台申请方式。未确认有相应系统接口，不预置“已查询通过”。
- 版本/归属栏：`人`＝个人实名材料须绑定 `F004–F006`；`考`＝考试制度/考次 `F002/F011`；`目`＝目标科目 `F014`；`源`＝签发机关/证据对象；`决`＝正式签发主体及范围。所有槽附带 `F044` 对应的**原件版本/哈希、接收时刻、被替代版本**，即使栏中只写简码也不可省略此组记录。
- 异常栏：`NM`=当前或触发条件下 `NEEDS_MATERIAL`；`UR`=已给但 `UNREADABLE`；`SU`=权威信息源失联 `SOURCE_UNAVAILABLE`；`PC`=适用政策尚未核实 `POLICY_UNCONFIRMED`；`HD`=需要有权人工判断；`NA`=未触发 `NOT_APPLICABLE`。绝不能把缺失、不可读或来源失联解释为已经不合格。

### 07.4 不强制重复上传与证明链防篡改

省自考“已有至少一门考试合格成绩”“已审定免试数”“准考证所属机构”、校内当前排考、国家考试报名点等**本来存在于有权系统**的事实，优先合法读取或由经认证人员核对；如接线不可用，生成来源待核，不逼学生自行制作“官方记录”。按 `SRC-009` 必交的身份证/毕业证/盖章档案仍由官方申报途径要求，不使用本地技术便捷性冲抵法定材料义务。

## 08 审核规则逐条清单

### 08.1 规则解释合同与证据层级（非行政裁决引擎）

以下 `R001` 起按**独立事实目标**连续编号，每条的 `T/F/U` 分别表示触发/事实为真、为假、尚未证实。`F` **不等于“拒绝申请”**：若本条是分支门禁，F 输出 `NOT_APPLICABLE` 并路由；若是政策要求的资格事实但官方证明确实不满足，记 `factMet=false`、`NEEDS_HUMAN_DECISION` 送有权机关按正式程序处置，**没有擅自增加的 `FAIL` 或 `REJECTED` 结果码**。U 必须按原因区分 `NEEDS_MATERIAL`（当阶段触发且应有材料未提供）、`UNREADABLE`（已有原件不能读）、`SOURCE_UNAVAILABLE`（权威核验端不可达）、`POLICY_UNCONFIRMED`（现行规范/授权缺失）、`CONFLICT`（可读来源矛盾）、`NEEDS_HUMAN_DECISION`（实质解释/裁量），不许任意取“通过”。

- **证据顺序**：省级规则原件/本批公告（`M003`）决定 A 的政策边界；当前专业计划/省考籍/签章档案/学信网/中国教育考试网（`M005/M008/M010/M013/M016/M017`）决定客观事实；有权学校考务/考点系统（`M018/M021/M022`）决定 B/C 的归属事实；学生自述/自行上传截图只作待验证线索。官方来源内部相互矛盾时不根据“哪个日期较新”直接覆盖，留 `CONFLICT` 交主管核。
- **阶段门禁**：`L0` 只分类/收意愿，`L1` 只核当下必要件，`L2` 核权威数据，`L3` 按真正退回原因补正，`L4` 才可消费当事决定 `M023`，`L5` 才可核 `M024` 执行，`L6` 只记录撤复请求及真实官方结论。所有规则产物为事实/待办；省自考**三级通过后**、B/C 有权机关签发后才存在外部正式决定。
- **重复与关联**：同一规则可在每个 `targetRef` 实例化，但**ID 不复制**。若多条规则核实同一证书，`R` 分别只负责入口资格、具体阈值、目标映射，不能各自生成一次免试权。每次输出存 `ruleId + caseId + regime + batch + targetRef + sourceVersion(s) + evaluatedAt + status + factMet? + issueIds + nextRole`；`L0` 不得要求本行仅在后续才生成的 M。

### 08.6 逐 R 的阶段有效性与裁定上限

1. `R001–R008` 只识别入口、归属、前置资格；`R009–R036` 面向省自考的证据和规则；`R037–R044` 面向 B/C/邻接路由；`R045–R054` 面向有权操作、最终决定、执行与证据治理。**只有 `R046/R047` 能报告收到外部正式决定的事实，不能由它们执行决定。**
2. `R014–R022` 的附表是 **2026-02-26省规则版本**。某一个目标可同时命中证书门槛和代码表，但当前专业计划未核或超过数量上限时，**不得计算整案“全部通过”**；不满足事实也不得用“未通过审批”作为模板直接写入学校系统。
3. A类结果应以 **`R006 R007 R008` + 具体分支 `R009…R013/R034` + 相关源成绩/表格 `R014…R031` + `R032/R033`（触发时）+ `R035/R036`（触发时）+ `R051…R054`** 的每目标核对为基础。B/C在权威授权和当期公告缺失时，纵使其它事实可核仍维持 `POLICY_UNCONFIRMED`。
4. 其他学段、遗留省自考/旧新计划、特别医疗/残疾安排和真实有权者的否定裁量均需有权机构确认。**本文件不是能在缺失官方签批/省系统数据时自动进行行政处理的规则集。**

### 09.3 版本/权威冲突算法约束（阶段设计）

1. **比较键**：`F002/F004/F011/F013/F014/F044` 以及材料签发主体。仅相同姓名不足匹配；分数证明中写的原课程、申请的目标课程、当前专业计划必须分别建立来源关联。对`F037`历史纸质转档另比对来源省份、目标四川、2016年以前、确认状态四轴，不将“已转出”误读成“已转入四川未确认”。
2. **更新传播**：证书 `M007/M009/M012`、成绩 `M008/M013`、身份 `M014` 或政策/计划 `M003/M017/M022` 更新，列出受影响 `F` 及当前依赖项；旧事实结论失效、留历史审计。省系统已正式作出的行政决定由原机关处理更正/复核，不能在 V3 改证据时自动删除。
3. **冲突分类**：同级正式来源相互冲突→`CONFLICT`，读取失败→`SOURCE_UNAVAILABLE`，文字/扫描不可辨→`UNREADABLE`，尚缺触发材料→`NEEDS_MATERIAL`，现行政策/审批授权未核→`POLICY_UNCONFIRMED`；所有需要裁量的事项→`NEEDS_HUMAN_DECISION`。某槽 `PASS_FACT` 仅意味该项事实核实，不能宣告整项申请批准。
4. **复合请求**：目标不同但材料重用时，以一份原件保留多条“证明目的/使用权”关联；只在权威证据同一且仍有效时复用其**事实**。没有真实授权不得把 B/C 个人便利、S02-T01 缓考、G50 课程替代或体育体测例外的**决定**互相映射。

### 10.1 八种互斥的规则实例主状态

| 主状态 | 唯一含义 | 禁止误解释 | 下一动作 |
| --- | --- | --- | --- |
| `PASS_FACT` | **本条规定的可核事实**获得相应证据支持；即便是 `R046/047`，也只表示已核实**外部决定存在** | 不是“全案合格”“学校审批通过”或可写成绩 | 移交下一事实核验；仅有权机构决定可触发后续执行 |
| `NOT_APPLICABLE` | 本规则/材料槽/阶段确未触发，或申请实属另一业务 | 不能把未来签章材料未到当“缺件”；不能隐去错误路由 | 保留明确路由及原因 |
| `NEEDS_MATERIAL` | **当前/条件已触发**，应提交的证据根本没有提供；且确实需要申请人提供或主管规定必须提交 | 不等于权威接口没有接通 | 向合法持有人提出**具体材料槽+用途**的补证待办 |
| `CONFLICT` | 已有可读来源就同一个关键事实、身份、目标、时间或权限产生矛盾 | 不能由 OCR 按新旧或“可信度打分”自动挑赢家 | 指定原签发/主责核验岗，附冲突两侧证据 |
| `UNREADABLE` | 已提供/可访问的证据因模糊、扫描缺页、损坏无法提取关键值 | 不能误作不存在或伪造 | 请提交者提供清晰版，旧版仍保留 |
| `SOURCE_UNAVAILABLE` | 需要依法查验的权威系统/原始记录目前无法访问或不可合法获取 | **不是学生缺材料、非资格否定、非“已查无此人”** | 记录故障/访问限制，合法重查或交官方线下核验 |
| `POLICY_UNCONFIRMED` | 缺少覆盖**当前考试制度/批次/岗位/措施**的有效授权规范或关键释义 | 不能靠外校制度、过期招生通知、上位原则填硬性校本门槛 | 到真实学校/省考院/当期考点取得正式政策或解释 |
| `NEEDS_HUMAN_DECISION` | 已有事实还需行政判断、证据真实性裁决、残疾合理便利可行性、负面事实处置、正式决定核实等 | 不能自动代替有权人员签字或默认拒绝 | 转有权机构，要求真实身份及授权操作凭据 |

**冲突与并发策略：** 一个 `caseId+ruleId+targetRef+evidenceDependencyVersion` 只有一个当前主状态，保留其他诊断为 `issue[]`，不可同一字段同时标 `PASS_FACT` 与 `CONFLICT`。处理顺序先判**制度与阶段是否适用**（不适用时 `NOT_APPLICABLE`），再查政策有效性；已触发的同条规则有多类障碍时主状态优先为 `CONFLICT > POLICY_UNCONFIRMED > UNREADABLE > SOURCE_UNAVAILABLE > NEEDS_MATERIAL > NEEDS_HUMAN_DECISION > PASS_FACT`，并保留所有非主障碍以供后续恢复。该优先序是产品提示排序而非法律上的证据优先级。已存在真实行政决定的效力应在单独 `authorityDecision` 对象中按原机关记录，不因新预审障碍立即被改写。

### 10.3 结论呈现与全案拦截

1. 每个目标课程/考试请求均展示 `事实已核 x / 存在问题 y / 待有权决定 z`，按八种状态分组列受影响 R 和材料版本；不同目标不得互抄“全部通过”。
2. 若任一必经 R 为 `POLICY_UNCONFIRMED/CONFLICT/NEEDS_HUMAN_DECISION`，首页和工作区**不能显示“可以自动批准”**；即便全部 R 为 `PASS_FACT`，也只显示“预审事实齐备，待主管审核”。
3. 涉健康/证号 `P3` 不在公共问题列表显示全文，替代为受限证据引用与可见的证明状态；向其他模板复用事实时只传经授权的最小信息。
4. `M023` 缺失（决定尚未产生）在 `L0–L3` 属 `NOT_APPLICABLE`；`M024` 未形成在 `L0–L4` 属 `NOT_APPLICABLE`；`M028` 尚未产生在正式复核**作出前**属 `NOT_APPLICABLE`。只有到对应法定阶段且源本应存在，才区分 `SOURCE_UNAVAILABLE` 与其他问题。

### 11.2 材料替换的定向失效算法

1. **追加不覆盖**：新增`M008@v2`保存新哈希、出具者、证书对应人和源成绩；`M008@v1`保留历史状态`SUPERSEDED`，绝不修改旧证据字节及原Run；`F025/F026/F027/F028`凡由旧版推导者标`STALE_DEPENDENCY`。
2. **按引用算影响域**：从 `EvidenceRef` 找直接依赖 v1 的 `R` 与 `targetRef`，如 A03 两门课程分别依赖同一成绩档案，则 `R023/024/027` 及附表匹配 `R020/R021` 与数量估计 `R028/029` 对有关目标重审；与 `M008`无依赖、且有效期未变的身份 `R002`、考点 `R039`无须重算。
3. **上游政策变更**：`M003/M017/M022`版本变化时重建所有涉及该 `policyVersion/targetPlanVersion` 的规则依赖与`R003/004/020…031/037…040`，不能仅因上传材料未变就维持旧结论。
4. **已发决定不自动撤销**：旧`M023`持续作为历史外部签署事实，但案卷标“证据基础发生变化，等待原机关核定是否更正/停用”；新的`M023`必须有独立权威`decisionId`或`supersedes`链。只重跑预审不能创建新正式决定。
5. **撤回后重提**：即使某制度容许撤回，重提也需当期**新正式受理回执**`M025`并核政策窗口，不能在同一案卷改本地`F045`就沿用原审核三级状态或旧签章。复核如改变结果，按新正式`M028`触发受影响目标和执行检查。

### 11.3 权限与时间的高风险拦截

- 法定/校本时限只可来自匹配的正式当期`SRC`。`SRC-009`2026秋自考受理期及`SRC-007`2026研考确认期不外推；**2027研考使用`SRC-016/017`网报/确认一体化，报考点便利申请的具体截止不由报名截止2026-10-24自动推导**。
- 本地系统不签发正式免试批文、不自行减免考务费、不把残疾证自动变成具体考场措施。省自考通告证实2026秋免试审定费8元/科，但后续是否变动须由省当期收费公告确认。
- `F041`必须从 Main/宿主实际认证与授权账本核验，Renderer字段、图片里的签名、模型“教务老师同意”一概不得触发`M023/M024`。
- 任何证据、复核或修改都需指向 `caseId / targetRef / originalAuthorityDecision / evidenceVersion`，不得错误关联同名学生、相似课程或历史考次。

### 12.2 必须升级人工处理的业务事实

1. **官方权责解释**：B 类个人免考/适当便利是否为现行校本独立事项、谁受理、何种程度改变考试要求；2017课程时长例外是否已被新规定替代。

3. **数量与多课裁量**：50%上限达到边界时的专业计划最低课程门数、实践数、并列分排序、已经认可的旧免试科目；省考院作实际驳回/更正，V3只算可审计风险。
4. **证书层次用语**：`SRC-008` 对结（肄）业申请专升本用“本科以上”，对其它处用“本科及以上”，不得由AI擅改原义，需省考试院解释后才启硬门槛。
5. **医学合理便利**：材料是否构成法规意义上合理便利、设备和考场安全、考试公平与具体措施，不能由图片识别模型/医学摘要作行政裁量。
6. **撤回/申诉实际效力**：各制度允许时点、权利救济、签发/送达时刻，必须逐制度取得原文；缺原文不自动删除案卷、不自动拒绝请求。
