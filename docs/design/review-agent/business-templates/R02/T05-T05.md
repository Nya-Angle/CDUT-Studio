## 01 唯一审核目的、申请人和负责机构

### 1.1 唯一决定对象

本模板的**审核对象**是某一教学改革与育人成果在指定奖项类别、年份/批次下，向校内归口部门提出成果奖申报或推荐的**事实材料与前置程序完备性**；对象键建议为“成果身份＋申报批次＋申报类别＋牵头申报主体”，而不是直接以个人获奖记录建案。它核实申报事项与批次匹配、成果说明与来源材料可追溯、成员/单位排序的声明与现有证据是否一致、是否已有必要的校内推荐/公示/核验决定，以及矛盾事项是否需要人工处理。

上位法规将教学成果定义为具有独创性、新颖性、实用性、对教育教学目标产生明显效果的教育教学方案；允许单位或个人依法申报，国家奖由有权教育行政机关依法评审批准授予（SRC-007 第 2–9 条）。**是否达到“优秀成果”、贡献是否充分、师德政治审查是否通过、推荐排序与名额如何取舍，是有权部门与专家人工判断，不是本模板规则计算的批准项**。

### 1.3 需要核验而不能代为决定的事实

1. 成果名称、申报类别、年份、申报单位与历史成果/项目的关联；同名、同内容或重复申报提示，但**相似不等于违规**。
2. 教学改革目标、实施过程、实践检验证明、推广应用、支撑成果的真实性和归属；材料可以承载事实，创新价值及获奖等级由专家判断。
3. 第一完成人、其他完成人、第一完成单位及合作单位的声明排序、参与贡献说明、相关人知情/授权与表单签字等**证据链**；成员排序不得仅凭文件顺序由 AI 重排。
4. 是否已有对应阶段的学院意见、校内推荐、公示处理结果和省级/国家级有效决定；后续阶段文件**不得**作为初始提交必交件。

### 2.3 可疑冲突的初步路由

- “只提交一项教改项目立项申请，无成果奖参评”：转 `T05-T02`，不得把项目立项结果当作教学成果奖。
- “获奖证书拿去评职称/核绩效”：转 `T02` 或校内有权人事/业绩认定；本模板可提供获奖来源引用，不再评奖。
- “教学竞赛奖、教材奖、科研奖、社科奖”：核对奖种后依相应模板/主管部门；不能因包含“教学”二字全部吸入本 ID。
- “成果报奖 + 教改项目结题 + 职称认定”复合材料：分别保留对应决定对象；本案仅核成果报奖部分，跨案引用权威结果与版本。

**第四轮阶段修正**：对 SC01/SC02 的 **2026 国家奖**，`L3→L4` 前的本单位公示并非可任意省略的“候选环节”：SRC-020/021 第三部分均明定单位范围内至少 5 工作日公示，新增 `F035/M022/R031`，公示由有权单位发布、初报 `L1` 不缺。该 5 工作日与教育部 `L5` 资格审查结果公示 90 日（SRC-018/019，2026-10-13 至 2027-01-10）是**两个不同公告**，必须绑定不同机关、对象和开始时点。

**正式报送不同形态**：2026 国家本科 `L4` 依 SRC-020 八核申报书、成果报告、应用及效果证明与条件支撑，含教材或视频才追加媒介要求；研究生 `L4` 依 SRC-021 八另核推荐单位汇总表、申报书/报告PDF盖章扫描，不得将本科要求改成研究生模板，均由全国教师管理信息系统报送、无需邮寄。四川省**2025** `L4` 则依 SRC-017 六（三）有网报加纸质原件三份的历史规定，绝不跨届迁入国家2026。

### 4.1 来源与现行性裁决

### 5.4 行政决定效力与引用

## 08 审核规则逐条清单

### 8.1 规则执行语义与证据级别

本节是**待学校审核确认的事实预审规则规范**，`R001–R038` 连续且不复用。每条 R 仅判其所列**独立事实对象**，不授予、拒绝、撤销奖项。规则结果是本案 Check 对某一材料版本的结论，不是行政审批状态。

- `trigger=T`：进入规则，在同一对象和对应阶段比较；`trigger=F`：输出 `NOT_APPLICABLE`，不索取该条件所需 M；`trigger=U`：若触发依据是政策或效力不明，`POLICY_UNCONFIRMED`；若是受控事实来源不可访问，`SOURCE_UNAVAILABLE`；若为人事权属/签发许可不明，`NEEDS_HUMAN_DECISION`；若缺申请者有责任提供的现阶段事实，`NEEDS_MATERIAL`。**未知不得偷偷当假/真**。
- `E1` 当前有效的国家/省当届原始规范或法定条文 `SRC-007/008/017/020/021`（省 2025 原文8页已核，仅供2025届）；`E2` CDUT 当届书面通知与授权（**目前未取得**，作为待补政策输入 `M001`）；`E3` 当事业务权威原决定/回执/受控组织身份/签发记录（`M006/M010/M012–M019`）；`E4` 申请人申报书、成员贡献声明与一手实施原件（`M002–M005/M007–M009/M011`）；`E5` 2022 旧表、2017/2021 旧做法、外校材料/新闻（仅作结构或线索）；`E6` OCR、文件名、模型推断（只能定位，**不能独立完成真实性证明**）。对同一事实，优先核 `E1/E2` 的适用效力和 `E3` 的签发效力，再以 `E4` 比对；**不能把更高层的项目决定用于替代其他授权目的的奖项决定**。
- 通用 PDF/OCR 可读性、杀毒、文档哈希生成和通用身份认证应调用 G50 或共享可信基础能力；本节只处理**教学成果奖特有的成果归属、批次、贡献、时点与阶段决定**。G50 目录候选键已核（SRC-022），但实际服务合同与接线未核，故“共用能力待映射”，不创建另一套通用算法。
- 本轮“时间检查”默认用 `policyEffectiveAt, policyPublishedAt, eventOccurredAt, submittedAt, signedAt, verifiedAt, sourceValidAt` 分开存储；冻结 Check 的 `policySnapshotId + fingerprint + targetVersion + sourceVersion`。不存在当前有效校本依据的限制（人数、名额、排名、实践年限算法、是否超时、文件份数、签章节点）**只出政策待证和人审任务，不能自动硬拒**。
- 表中结果栏的 `PASS_FACT` 仅指规则要核的**可观察关系**满足；缺证明用 `NEEDS_MATERIAL`，两份可读原件抵触用 `CONFLICT`，文件已到但无法解读用 `UNREADABLE`，权威系统失联用 `SOURCE_UNAVAILABLE`，规则效力未定用 `POLICY_UNCONFIRMED`，需要解释/裁量/有效签批用 `NEEDS_HUMAN_DECISION`。完整互斥契约见 §10。

1. **权威性不等于最新上传**：奖种/批次以发布机关 `M001` 为主；`M002` 是申报人的声明，`M003/M004/M005` 作为事实佐证；项目批准 `M006` 只能证明项目，不能支配成果奖 `M019`；获奖效力以授奖机关原决定 `M019` 为主（SRC-007/013/015–017）。事实发生时间、记录时间、文件产生时间分别保存。
2. **身份和签发权逐对象核对**：`F006` 为受控认证经办者，`F007` 为申请主体陈述，`F017` 为每一完成人，`F022` 为合作单位授权；四者不能互相代替。签章图像、OCR、上传者自称“教务处”不构成审批 `F027`。
3. **替换有影响集合**：改变成果名/类别影响 `F009,F002,F003` 与申报表；更换成员、排序影响 `F016–F019,M007/M008`；更换单位影响 `F020–F022,M009`；改变实践时间影响 `F013–F015,M004/M005`；更换旧奖/项目佐证影响 `F023/F024,M006/M010`。将影响集同 `M021` 固定到新 Run，旧 Run 对旧版本保留审计、**不得作为新版本事实的 PASS_FACT**。
4. **跨案/跨模板只读引用**：通用身份/签章/可读性只有核实到 G50 的真实模板键和决定版本时才复用；项目结题读取 `T05-T02` 决定 `M006`，课程/教材读取其各自授权成果；个人职称、奖励、绩效转 `T02` 并引用 `M019` 有效记录。若 G50 或其他决定原站不可得，输出 `SOURCE_UNAVAILABLE`，不编造决定、不同步修改他案。
5. **行政裁量最小化**：是否允许更改团队排序、是否认可联合贡献、当届名额优先级、最终推荐、公示异议、资格审查、授奖/撤奖，由各自有权机构依法判断。本规则层只输出事实证据与人工待办；各类 `CONFLICT` 可并存，不可用材料“总齐全”覆盖。

### 9.4 决策输出的阶段真值与追踪

`PASS_FACT` 仅指特定 F 与特定版本 M 的事实一致；`NOT_APPLICABLE` 表示阶段未到/条件为假；`NEEDS_MATERIAL` 为应有事实证据缺少；`UNREADABLE` 为证据已到但无法识别；`SOURCE_UNAVAILABLE` 为权威来源暂不可取得；`POLICY_UNCONFIRMED` 为适用条款与效力不明；`CONFLICT` 为两个可读来源矛盾；`NEEDS_HUMAN_DECISION` 为真实性/贡献/政策裁量或权限争议。**以上任何一个均不等于学校推荐、国家省级资格通过或授奖决定。**

`R001–R038` 所有规则共用 §10 结果结构；当一个审查目标同时有两类问题（如政策网页打不开且实施证明模糊）时，在对应 R/目标下保留**独立问题记录**，不能只存一个“总失败”。`R020` 的材料版本变化向依赖 R 扩散，已由有权人签发的 `R023/R027` 记录只挂“需核查后续效力”，不能技术性撤销。

## 10 结果状态、问题与待办输出契约

### 10.1 八个互斥结果语义与取值条件

单条 Check 对**单个目标、单个来源版本**只出下列八值之一；一个案例下不同 Check 可分别为不同值。**不设 `APPROVED`、`REJECTED`、`AWARDED` 等模型自动行政决定码。**

| 结果码 | 精确含义、必须满足的判定条件 | 不能混用；可执行待办 |
| --- | --- | --- |
| `PASS_FACT` | 触发为真，相关当前事实有可读证据、来源时效与声明一致；来源/版本可回溯。只表示该事实核查达成 | 不代表专家认可、学校推荐、官方资格审查通过或授奖。可进入下一**人工**办理节点。 |
| `NOT_APPLICABLE` | 触发明确为假、当届无该材料条件，或该文件尚未到生成阶段（如初报尚无 `M019`） | **不是缺件，不是暂时查不到**；记录不适用理由与依据。 |
| `NEEDS_MATERIAL` | 触发真且现阶段已应具备的申报事实证明未提供，或必备证明实质内容空缺 | `M012–M019` 初报不得标此码；待办指向对应 M/字段/提交人。 |
| `CONFLICT` | 两个或以上**可读、可归属**的声明或权威记录，对同一对象和有效期有不一致的值 | OCR 未辨识不能直接判冲突；保留双方版本、页码和授权人，交澄清。 |
| `UNREADABLE` | 相关文件**已提交**且可定位，但页、签章/扫描区域/数字等无法可靠读出 | 不能当“没提交”，保留原件，要求清晰件或人工原件核验；通用识别复用 G50 能力。 |
| `SOURCE_UNAVAILABLE` | 应调用的权威原站、校务系统或上游决定暂不可访问，**不是**申请人没有上传文件 | 保留链接、最近成功版本、访问失败时间；找系统/档案持有人，不能强令重复上传已有权威记录。 |
| `POLICY_UNCONFIRMED` | 该批次强制条件、时效、限制、责任机关或附件**未从现行原文确认**，因而不能判适用 | 不把 2021/2022 样本、外校 SRC-012 或仅新闻宣传填成“现行规章”；发给政策归口。 |
| `NEEDS_HUMAN_DECISION` | 有权人员必须判断资格/贡献价值/权属、授权范围、期限例外、撤回/复核、签批是否合法 | 不能靠材料完整性、AI 置信度或前端标志转 `PASS_FACT`；待办指定**有权**机构。 |

**判定优先关系**：先评触发 `F`→`NOT_APPLICABLE`；触发 `U` 依未知根因分政策/来源/权限/当前材料；触发 `T` 才检查有无当前材料、可读性、跨源一致性。一个目标若存在多条独立待办则按规则/对象拆出多张 Issue，不用“最高风险码”吞掉其他原因。对同一 Check 的固定输出由有权核验者完成，不能因视觉材料全绿提升为“批准”。

## 11 补件、撤回、版本更新、复核与人工决定

### 11.1 同一案卷内的事件链与权限前置

流程状态 `L0–L6` 保留在 §03；补件、撤回、更正、异议、复核分别是**事件支线**，不拆成新的模板 ID。下表是安全状态约束，不冒充校内已经发布的线上流程；法律上能否受理、期限、哪个机构签批必须由当届规范与真实授权确认。

| 事件 / 发起阶段 | 允许的候选状态序列 | 当前必须存在的前置证据、操作角色 | 事实核验与禁令 |
| --- | --- | --- | --- |
| 初次提交 `L1` | `DRAFT → SUBMITTED_FOR_FACT_REVIEW` | 成果主体/合法代理 `R005–R008`；现阶段 `M002/M004` 及按条件材料 | 无 `M012–M019` 不算缺件；政策待证仍可保存草稿，不自动受理/推荐。 |
| 补件与退回 `L2` | `ISSUE_OPEN → SUPPLEMENT_REQUESTED → MATERIAL_UPDATED → RECHECK_PENDING → FACT_RECHECKED` | 归口/学院有权发出问题（`R021`）；申请者仅补问题对应 M，写 `M021` 版本差异 | 补正时限当届未核不可自动判逾期；旧 Check 变为 `SUPERSEDED_FOR_CURRENT_VERSION`，保留历史。 |
| 修订排序/单位/实践事实 `L1–L4` | `CHANGE_REQUESTED → IMPACT_ASSESSED → HUMAN_ACCEPTED/REJECTED → RECHECKED` | 申请人/各权利人提出；`R014–R017/R020` + 本届变更权限 | 已推荐/报送后可能须重走公示或上报，由有权者裁定；技术可定向重核**不能**擅改 `M014/M017` 官方记录。 |
| 撤回 `L1–L4` | `WITHDRAW_REQUESTED → AUTHORITY_REVIEW → WITHDRAW_ACCEPTED/WITHDRAW_DENIED` | 本人或合法代理 `R005/R006/R028`，明确案卷、批次、版本、原因 `M020`；有权主体签处置 | **请求≠撤回生效**；未经批准不得标 `WITHDRAWN`，已对外送审需按相应平台/机关规范处理。 |
| 撤回后重提 | `WITHDRAW_ACCEPTED → RESUBMISSION_REQUESTED → POLICY_CHECK → NEW_ATTEMPT/NEW_VERSION` | 先有有效撤回决定及同届重提规则 `M001/M020`；当事人重新确认成员/单位授权 | 是否同批次可重提未知；被禁止时只能记录申请与人审。新尝试不得继承已被替换材料的旧 `PASS_FACT`。 |
| 公示异议/成果权属争议 `L3–L5` | `OBJECTION_SUBMITTED → JURISDICTION_CHECK → ACCEPTED/NOT_ACCEPTED → HUMAN_DISPOSITION` | 权利人争议对象、证据锚点 `M015/M020`；国家成果权属异议依法依 SRC-007 第 10 条 | 国家公示 90 日权属异议不是学校一般复核期；不同案由不得统一“上诉成功”。 |
| 校内事实复核或推荐异议 `L2/L3` | `REVIEW_REQUESTED → AUTHORITY_CHECK → FACT_REVIEW/FORMAL_REVIEW → DECISION_RECORDED` | 申请人说明复核理由、原 `ruleId/checkId/sourceVersion`，真正被授权复核者 `M020` | 事实错误可以生成新 Check；学校推荐是否合法需另有有权签批记录，原决定保留。 |
| 外部资格、授奖与撤销 `L4–L6` | `AUTHORITATIVE_RECORD_ARRIVED → VALIDITY_VERIFIED → REFERENCED/CHALLENGED` | `R026/R027` 读取 `M018/M019`，权威机关另行签发撤销/更正 | `PASS_FACT` 不能改写资格、获奖与撤销；T02 等下游对来源有效性变化重新引用，不在本案裁算奖励。 |

**权限不满足是显式阻断**：无受控认证、代理授权不明、校级签发权不明、外部机关决定找不到时，仍能留申请者请求/问题的**非生效事件**，但不得写“申请已撤回”“复核通过”“学校已推荐”“授奖已生效”。对任何发给外部机关的动作，保持真实回执与报送主体两条证据链。`F033/M020` 的请求记录与有权决定记录必须有不同事件 ID 和签发人。

### 11.2.1 第四轮新增材料的定向重审

### 11.3 完成条件与真正闭环

1. **事实预审闭环**：当前阶段所有触发为真的 R 都已产出可定位 Check；`NEEDS_*` / `CONFLICT` / `UNREADABLE` / `SOURCE_UNAVAILABLE` 问题均有负责人、证据位置、下一动作及是否允许继续流转的**人工决定**。`PASS_FACT` 总量不构成审批批准。
2. **校内推荐闭环**：只有已核权限的学校机构签发 `M014`，并按当届规定完成必要公示/异议后，才可引用“学校已推荐”的真实 `AuthoritativeDecisionRef`；缺通知/授权不模拟通过。
3. **对外报送/资格闭环**：必须有真实平台 `M017` 与主管机关 `M018` 逐对象匹配。2026 国家本科/研究生项目资格公示 SRC-018/019 证明一个公共阶段，不代表本案中的任一成果已通过。
4. **最终授奖/引用闭环**：仅 `M019` 的有权授奖决定使“已授奖”成为可引用事实；是否计入职称、绩效、奖励由 `T02` 独立处理。撤销或修改通知下游重新读取源效力，不二次评奖。
