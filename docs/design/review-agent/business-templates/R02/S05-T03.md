## 01 唯一审核目的、申请人和负责机构

**唯一事实目的**：就某一学生、培养方案版本和《劳动教育》课程（实践部分）的**具体实践项目**，核对是否有适用的课程/活动归属、可归属于该学生的真实参加与过程表现证据、可转换的学时/学周或课程考核记录；生成待人工核定的认定建议与问题清单。活动可包括生活生产劳动、公益服务岗位、专业创新劳动等，但不得仅凭“参加活动”推导出学时数或合格成绩。相关课程的理论部分只作为培养方案归属比对，不在本模板重做理论考试评分。[SRC-001][SRC-003][SRC-005]

- **学生发起**：学生为本人请求补录实践经历、认定未入账的合格项目或要求对事实记录作核查；不可代另一个学生签署申请。班级/学院可依正式课程安排批量发起核对，必须具有学校可信委托和逐人对象绑定。
- **教学端发起**：经学校授权的课程负责教师、学院劳动教育负责人或教学管理岗位可发起班级/项目记录校核；具有批量发起权不等于有任意学生成绩修改权。
- **资料形成者**：课程教师、现场劳动指导员、后勤/宿管现场检查人员、校内项目组织者、公益服务合作单位可分别**证实自己记录的事实**；班委/团学骨干的名单只能是待核辅助线索。
- **真正有权者**：项目事实确认由具体组织/检查责任方；劳动教育课程表现与实践认定由**当期校级实施方案指定的课程教师、学院课程管理/教务权限主体**确认，课程成绩正式入账/更正由学校教务管理授权链完成。仅从公开证据可确认学校教务处承担课程管理与成绩管理工作、任课教师对学习成绩评定负责，**尚不能确认每一劳动模块具体签发节点**。[SRC-008][SRC-009]
- **输出物**：`fact_findings[]`、`proposed_recognition[]`、`issues[]`、`human_tasks[]`，有权机构签署后才形成`authoritative_decision_ref`；AI/OCR/照片不能签发官方学时或成绩。

## 03 业务生命周期与办理情形矩阵

### 03.1 对象及状态

`Case(student_id, program_version, course_instance, term)`含若干`ActivityClaim(activity_id, module, observed_duration, evidence_version, recognition_version)`。状态：`DRAFT → SUBMITTED → FACT_CHECKED`，有问题进入`NEEDS_MATERIAL/CONFLICT/UNREADABLE/SOURCE_UNAVAILABLE/POLICY_UNCONFIRMED/NEEDS_HUMAN_DECISION`的待办分支；办毕进入`HUMAN_RECOGNIZED/HUMAN_NOT_RECOGNIZED`（可信签发），如应入成绩系统再进入`POSTED`，可另触发`WITHDRAW_REQUESTED`、`REVIEW_REQUESTED`、`SUPERSEDED`。**`FACT_CHECKED`非审批终态**，每一状态变更记录actor、权限、目标版本、依据、时间。学生撤回请求不抹去已签课程成绩。

### 03.3 前置、触发与阶段边界

1. `DRAFT`只要学生自己对某项目的申报信息及合法授权；**不能在此时要求M007课程评分、M014期末成绩、M019复核决定**。
2. `SUBMITTED`先查身份/培养方案/课程实例；没有适用范围时停止形式化补件提示，询问教学端政策配置。
3. `ACTIVITY_COMPLETED`才校验考勤、现场工作质量、实际时长、组织者登记。手写签到和宿管/指导员台账不相同时走冲突。
4. `TERM_FINALIZATION`才读取课程评定量规及课程成绩草稿。无权模型只能准备审核建议，正式成绩依授权系统提交。
5. `POSTED`后的变更必须基于**源记录纠错→教师申请变更→正式教务更正**；学生对成绩的复核请求另走S02-T06。迟交照片不能自动覆盖已有记录。

## 05 角色、权限与可信数据边界

| 角色 | 可提出/提供 | 能签署的范围 | 系统可信性与禁止动作 |

**最小数据**：姓名/学号作为普通个人信息标识，精确出勤轨迹、医疗/残障和未成年信息、真实个人身份证号码可能高度敏感；上传前应按合法授权、最小必要、角色限读、审计留痕和保留期限配置处理[SRC-017]。外部公益单位证明只保存最少可核字段，不全量复制通讯录/位置轨迹；无法访问校内系统输出`SOURCE_UNAVAILABLE`，不得虚构服务器已核。

### 08.1 独立状态与权限约束

1. `PASS_FACT`仅赋予单规则事实成立标志；**没有**`AUTO_APPROVED`结果。`NOT_APPLICABLE`代表此条规则/课程范围不适用，不能拿它抵扣尚需学时。
2. `NEEDS_MATERIAL`是申请/权威持有人能够补充的**当前阶段**材料；若唯一缺口是学校政策、需有权判断或后台故障，则分别是`POLICY_UNCONFIRMED`、`NEEDS_HUMAN_DECISION`或`SOURCE_UNAVAILABLE`，不能无限要求学生上传。
3. 审查器对缺席、差评、疑似伪造等不直接给处分；仅作记录冲突或有权人工任务。对于假证件、组织安全风险，保留审计证据并按学校正式程序转办。
4. 评分和学时两个量纲分开：计时真≠质量合格，现场评语真≠完整课程学时，二者都≠正式成绩已入账。

## 09 触发条件、冲突和复合场景

### 09.1 组合认定算法（仅准备建议）

1. **先范围后材料**：R001–R005确定学段、专业、版次和课程实例；不适用即路由，不向学生索要无关课程材料。R006–R008对每个活动建立一个可追溯组织任务键。
2. **逐项目核查**：R009–R016针对每一活动的出勤、时段、评价、签发者和跨模板引用建立分项事实结果；只合并相同来源版本的无冲突区间，不以照片“打卡次数”直接计算学时。
3. **先规则再数量**：R017要求校本换算规则可定位且量纲一致；R018–R020在可信已签认定台账上核对额度和去重；缺公式时允许输出“已核实参加某活动、可认定量未知”，不得打印带小数的伪学时。
4. **课程表现另算**：R021–R025只在当期课程考核期触发，以教师批准的评价量规和原始评价记录产生*待签建议*，正式成绩由学校权限链入账。
5. **例外与许可**：R028–R030按具体学生/活动条件触发，课程出勤核验可以先完成，但不能掩盖尚需安全或场地批准、实际参与是否允许的问题。
6. **决定后事件**：R026–R027和R031–R032处理异议、撤回、版本变动；总评或其他S/T消费**可信签发结论引用**，不是本模板生成的文字结论。

| 冲突类型 | 具体比对和行动 | 禁止的捷径 |
| --- | --- | --- |
| 活动通知与课程教学方案冲突 | 两者各自记录签发单位/适用学年，向课程负责人确认何者支配课程认定；项目可以真实举办但不一定计课程 | 因有通知就自动给时长 |
| 原始签到与学生照片冲突 | 通过活动ID、学生ID、时间、签到设备/原始检查员核对；要求现场持有人出具更正回执 | “人脸相似”推翻缺勤 |
| 校外公益服务证明与S05-T02工时不同 | 保留两个编号和原单位源证据，先由志愿事项更正其工时，再按劳动课程映射政策计算 | 以较大工时为准/两处都加 |
| 2025专业培养方案与2026学院通知不同 | 分开比较“修读要求”和“活动安排”；如果专业方案无明确小时换算，标未知 | 将1.5周=12/48/60小时等强行换算 |
| 历史规章与当期校本课程细则不一致 | 保留两版policy snapshot，按签发机关、有效范围、替代条款确定优先级；无法确定请求教务法效确认 | 把旧制度汇编写成2026现行统一规则 |
| 活动区间重复/多个学生共用签到 | 按`student+activity+time slice`识别冲突，查原始签名、汇总分摊逻辑及是否实际多人参与；分别绑定个人证据 | 一个学生证明复制给整班 |
| 签发人与授权关系冲突 | 可信服务查签发有效期与课程/项目范围，生成权限异常待办 | OCR盖章当作权限证明 |
| 录入的课程成绩与过程分项不一致 | 教师核验分项源、按经批准量规重算，已发布成绩走正式更正 | 本模板直接写成绩字段 |

**重复计量**：同一次活动既可以在志愿体系有一份“公益服务经历”事实，也可能按学校政策在劳动教育体系有单独认定；不是天然非法，也不是天然允许。必须具备明确的课程映射与各体系的禁止/允许重复政策，独立的`RecognitionLedger`按目标课程维度防**同一劳动课二次加算**；跨体系同时计入是否允许标`POLICY_UNCONFIRMED`等待课程负责人。跨项目重复使用同一事实时只能引用不可复制签发。

### 10.2 八类互斥事实状态与待办

| `status` | 用户可见文案（示例） | 下一办理角色 / 禁止行为 |
| --- | --- | --- |
| `PASS_FACT` | “该活动原始签到与本人归属一致（仅事实通过）” | 如其他规则已齐，交课程有权人员核定；不能标“学校已批” |
| `NOT_APPLICABLE` | “该项目不属于当前课程模块，请选择志愿服务或社会实践事项” | 用户重新路由；不称课程失败 |
| `NEEDS_MATERIAL` | “缺少该次活动的现场考勤回执（M006）” | 标注持有人为后勤/指导员或本人，而非一概学生；可先继续其余规则 |
| `CONFLICT` | “本次申报4小时、现场记录2小时，来源不一致” | 双方核查，冻结此活动定量认定；不取最大值 |
| `UNREADABLE` | “M007@v2是损坏扫描件，无法读取签发评价” | 出具部门重导原件/使用可信服务替代；不要当作零分 |
| `SOURCE_UNAVAILABLE` | “教务台账连接失败，现无法确定是否重复入账” | 平台/课程管理员修复链接或可信离线回执，不要求上传他人数据 |
| `POLICY_UNCONFIRMED` | “当前专业‘学周→学时’规则尚无可核对的校本文件” | 学院/教务确认版本与换算公式；不能拿东南大学标准硬算 |
| `NEEDS_HUMAN_DECISION` | “考勤事实已核，但特殊替代是否认可须课程负责人审批” | 具体有权签发岗位处理；模型不作自由裁量 |

**每一问题强制键**：`issue_id`, `rule_id`, `status`, `person_ref`, `target_activity/course`, `field_id`, `material_slot`, `material_version`, `source_id`, `source_version`, `policy_scope`, `next_actor_role`, `requested_action`, `observed_at`, `review_run_id`。同一活动可同时有R009出勤冲突与R013成果缺件，输出**两条问题**，不得合并为“材料不完整”。材料与规则是多对多关联，但每一结论与明确target及版号一一对应。

**汇总原则**：可以输出`fact_evidence_coverage=verified`与`human_decision_pending=true`并存；`PASS_FACT`总数不是通过率；如果所有可核事实成立而当期学时配额政策未知，最终仍不能产生确定认定量/学分/成绩。

## 11 补件、撤回、版本更新、复核与人工决定

### 11.1 不可变事件与定向重审

| 事件 | 前置与操作者 | 状态变化及具体副作用 |
| --- | --- | --- |
| `ClaimSubmitted` | 本人/有权批量发起者，可信身份；课程目标已定位 | 创建Case/Claim版本，冻结`planId + fingerprint + Check×target/sourceVersion` |
| `MaterialReceived` | 目标材料持有人或本人授权上传 | 新M版本不可覆盖老文件；仅关联受影响F，R032生成失效集 |
| `SourceVerified` | 现场有权组织/学校可信查询结果 | 从`NEEDS_MATERIAL/SOURCE_UNAVAILABLE/CONFLICT`重核其引用R；保留旧证据矛盾记录 |
| `PolicySnapshotConfirmed` | 教务/课程主管签发当期版 | 重新计算R003/R007/R017/R018/R021等与该政策版本依赖的规则；禁止全校传播单院规则 |
| `RecognitionProposed` | 事实核验完成，课程审核员发起 | 仅待签建议，至少绑定学生、课、项目、时段、规则、证据指纹 |
| `RecognitionDecided` | 已校验有权课程签发者 | 才写`recognition_decision_id`，使用服务端事务/版本CAS，旧观察值不得重复生效 |
| `GradePostRequested` | 课程有权教师/教务授权流程 | 不由模型签分，记录向教务系统提交的可信结果和外部事务ID |
| `GradePosted` | 学校成绩系统回执 | 只接受可信系统返回的成绩版号与正式入账时间；不可用截图模拟 |
| `WithdrawRequested` | 本人/合法代理，验证原案版本 | **未决定**可关闭提议但保留审计；**已签/已发布**转原部门撤销/成绩更正流程，不删除历史决定 |
| `ReviewRequested` | 本人对具体R事实提出异议或正式成绩复核 | 项目事实争议本案定向重审；正式课程成绩异议转`S02-T06`；教师改分走`T01-T08` |
| `DecisionSuperseded` | 有权复核/更正签发，引用old/new版本 | 更新可消费决定指针，关联消费者收到失效通知；保留旧决定供审计 |

**例**：M006@v1记录2小时，学生补充M006@v2（由原现场单位确认4小时），只重审R009–R012、R017–R020及受影响的R025、R032；R003培养方案、R005选课关系等不变时不复跑。若该活动参与影响课程评分，追加R021–R023；若学时上限政策更换，则所有引用该`conversion_policy`的活动受影响，不得仅重算最新上传的一个材料。

### 11.2 归属、CAS与重审安全

- **写权限**：由可信Main/后端唯一案卷事务主体写Case/ReviewRun/Decision/Outbox；UI/Renderer/Agent只提交命令和候选，不能发可信actor或直接改已发布成绩。
- **新案/重审**：新案只CAS创建一次，重复点击沿同一ID幂等；原Run绑定`entryRunId`，任何批量finalizer不得拿缺/错Run定稿；旧`Observation`随所引材料/政策版本变化立即失效，禁止旧`run@rev`冒充新判断。
- **补件**：一次允许多个M升级，每个material独立`sourceVersion`，服务端构建依赖闭包；重审完成才提议新课程认定量。材料缺一张非核心照片可继续其余事实检查。
- **申诉处理**：保留学生请求原文/时间、正式受理编号、来源文件与人工复核意见；若无法确认现行法定/校本期限，标`POLICY_UNCONFIRMED`，不能根据旧汇编“10个工作日”直接驳回。
- **数据权利**：因数据错误产生的更正要区分`原始现场来源更正`、`课程认定决定替代`、`教务成绩发布更正`三个独立动作，逐一可审计且撤销有权限边界。

## 13 场景演练与反例

以下使用合成`STU-Axx`、`ACT-Bxx`，时间与数字仅测试输入，不代表学校政策。每例列“预期规则→状态→下一处理角色”，并验证其他无关规则不被误改。

| 场景 | 合成输入、应触发R与预期输出 | 防止的错误 |
| --- | --- | --- |
| E01 正常事实核对 | STU-A01适用方案/已选实践课程，有学院组织ACT-B01与原始签到，现场时段一致；R001–R014中适用项`PASS_FACT`，R017若无校本换算则`POLICY_UNCONFIRMED`，课程负责人待签 | 把事实齐全当成认定时长/课程成绩已通过 |
| E02 少量缺件可继续 | STU-A02身份证/课程/排班、原始到场已可核，仅项目要求的指导员评价M007未到；R013`NEEDS_MATERIAL`指向指导员，其他R保留结果，不阻塞整个初审 | 把课程未来成绩M014或非关键附件列为全案提交失败 |
| E03 考勤冲突 | STU-A03申报ACT-B03四小时，现场原记录两小时；R010`CONFLICT`，`M006@v1`绑定争议；等待现场负责人更正 | 直接取较大值或凭截图替代现场日志 |
| E04 原件不可读 | STU-A04上传损坏的M007@v2，其他考勤可读；R013/R014因材料不可读转`UNREADABLE`，指导员重新导出 | 当作劳动不合格或把OCR空白当零分 |
| E05 源不可达 | STU-A05已完成项目，但教务成绩/台账不可查询；R019/R020/R023对应`SOURCE_UNAVAILABLE`，联系教务管理员 | 把“查不到”当作从未参加或从未入账 |
| E06 重传/定向重审 | STU-A06的M006@v1改为原单位签发的M006@v2，观察时长变化；R032触发影响闭包：R009–R012/R017–R020/R025，身份R001与方案R003继续有效 | 重放旧run@v1或全案无差别重跑 |
| E07 撤回后复核 | STU-A07未签认定前要求撤回，R031`PASS_FACT`停止待签；若已有正式成绩则`NEEDS_HUMAN_DECISION`并转有权变更，学生异议按R026分路由 | 学生删除已发布成绩，或以撤回替代成绩复核 |
| E08 外部公益劳动与志愿重合 | STU-A08有S05-T02志愿证明3小时，申请劳动实践3小时；R015可核经历，但R016/R017无课程映射则`POLICY_UNCONFIRMED`，由课程负责人确认是否可转换 | “志愿=劳动”自动等额重复给学时 |
| E09 学周与小时偷换 | STU-A09的专业培养方案实践1.5**周**，活动清单写30**小时**；R012/R017需有效换算`POLICY_UNCONFIRMED`，M005–M007事实照核 | 把学周乘任意每周小时数而造虚假达标 |
| E10 宿舍整班名单伪造 | 某班长上传完整班级劳动合影和自填签到表，STU-A10在原始指导员台账不在场；R009`CONFLICT`，R014签发权不足，查班级及现场持有人 | 一份合影给整班每人统一学时 |
| E11 同源时段重复入账 | STU-A11用同一ACT-B11在两个劳动课程项目申报同一时间片；R019检查已有占用`CONFLICT`，R020冻结汇总直到去重 | 不同表单重复算同一劳动时段 |
| E12 未授权社团安全活动 | ACT-B12是学生社团校外集体劳动，场地/外出/活动安全相关G决定缺失；R030`NEEDS_HUMAN_DECISION`路由G04/G05等，考勤事实可单独保存但不说明活动已合规获批 | 用实践证明替代组织、安全或经费许可 |
| E13 课程成绩争议 | STU-A13认为教务系统课程分数错误，提出本模板“补几小时就改分”；R026确认为已发布成绩→`NOT_APPLICABLE`并转S02-T06；任课教师改分走T01-T08 | 模型在课程资料核对环节绕开教务改分 |
| E14 跨届算法污染 | STU-A14所在2023级被错误套用2025版地球物理卓越班“1.5周”规则；R003`CONFLICT`、R021`POLICY_UNCONFIRMED`，恢复对应年级/专业方案 | 新版某专业规则覆盖旧年级/其他专业 |
| E15 现场“差评”与人工判断 | STU-A15出勤属实，现场评语称劳动表现欠佳；R009`PASS_FACT`，R013有证据但是否达标需R021课程量规；无量规`POLICY_UNCONFIRMED`，教师决定 | 有学时就强制成绩及格，或由模型主观打不及格 |
| E16 特殊补做与敏感材料 | STU-A16需合理替代，有有效学校签发“准予替代项目”回执但不暴露医疗诊断；R028/R029核回执与补做事实，学时算法仍依据M011，隐私字段仅限权查阅 | 强制公开诊断书、把外校“每学期6小时”套到成理 |
