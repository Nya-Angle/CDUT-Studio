## 源完整性核验

五份 `research-original` 当前 GitHub blob 的 UTF-8 字节数均比清单 `bytes` 少 1；逐份计算 `SHA256(原始 blob 字节 + 一个 LF)` 均与清单 SHA-256 精确匹配。该差异与 `00_统一审查标准.md` §1 记载的 `LINE_ENDING_DRIFT_ONE_LF` 一致，不是原件正文损坏。T08-T03/T08-T04/T08-T05 审阅副本保持与原件 blob 字节一致；T08-T01 审阅副本只更正 SRC-008 的失效状态一行，T08-T02 审阅副本只更正 SRC-011 来源记录及其 §14 评估行。运行元数据中的 `sourceDocumentSha256` 记录审阅副本实际字节哈希，`manifestExpectedSha256` 记录清单预期值，二者不混用。另 T08-T05 清单 `source_snapshot=2026-10-22` 与原件 `research_as_of=2026-10-23` 不一致；只登记，不擅自修清单。
