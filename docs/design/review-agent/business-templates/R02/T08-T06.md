## 01 事项归属、角色与不可越权的决定

1. **申请人**：拟进站或在站博士后本人。代办须留有真实授权和身份来源，单凭上传表格内姓名不足以证明签署权。
2. **合作导师**：提供科研课题、计划和相应指导、评议或同意材料；导师签字只代表其实际被授权范围，不替代学术委员会或设站单位正式决定（SRC-002 第10—11、16、28条）。
3. **专家学术委员会/考核专家组**：开题、中期、出站学术把关与书面评价。专家组成、回避、表决、校内签发方式仍待确认（SRC-002 第11、15—17、29条）。
4. **设站单位/校内博管归口部门**：是博士后培养管理责任主体，核实本人、专业、岗位、合同/协议和材料，组织考核，作真实办理决定或登记；不能从职能名称推断某个具体人员拥有最终签章权（SRC-001 第5条）。
5. **省级/国家系统与管理部门**：网上信息、备案、变更和出站证明按规定在受信系统办理；本地审核程序只保留可核引用和回执，不代表已提交或已获受理（SRC-001 第19—21条、SRC-002 第8、25、28条）。

**跨模板路由**：科研助理招聘/一般项目劳动合同归 T08-T01/T08-T02；普通项目续聘调薪归 T08-T03；一般离岗/合同解除归 T08-T04；实验室授权变更归 T08-T05；正式教师岗位聘任、人事调动、科研项目调整或涉密管理分别转对应独立事项。本模板不得沿用其他批次的录用/解除决定，也不得依同一次 Run 自动触发另一业务的审批。

## 05 关键业务对象与证据链

- `PersonIdentity`（本人身份、博士学位、特殊身份/资格）与 `PostdocStation`（科研流动站/工作站/基地及联合资格）分别核验。
- `StageIntent`（A—J 其中一个主阶段，允许声明补件/复核的辅助动作）有独立版本；不得把进站、考核、延期、出站申请合成同一自动批准。
- `ResearchPlan` 包含导师、课题、计划版本及签署事实；成果/论文/专利/保密项目仅登记必要验证引用，不在一般公网传全文。
- `AssessmentRecord` 区分开题、中期、年度、出站四种学术/组织评价，不能互相冒名；由有权组织形成的书面记录才具审查事实价值。
- `DecisionRecord` 与 `SystemReceipt` 分开保存并核时效；申报材料、导师意见、系统回执、正式决定四层不可跨越。
- 对每条检查记录 `stage+criterionId+F/M/SRC+sourceVersion+result+actor/time+unresolved`；用户重新上传材料后旧引用只能作为历史版本。

## 10 结果码与互斥语义

| 结果码 | 唯一语义 | 下一角色 / 禁止动作 |
| --- | --- | --- |
| `PASS_FACT` | 某**事实项**已有可信材料支持；不是政策合格、考核通过或批准 | reviewer 汇总事实，交有权人 |
| `NOT_APPLICABLE` | 已有可核情形/政策证据证明此材料或规则不适用 | reviewer 留触发依据；未知不可当 N/A |
| `NEEDS_MATERIAL` | 需要补充具体材料，须指出 M ID、原因和阶段 | applicant 补件；少量缺件可预审后补齐 |
| `SOURCE_UNREADABLE` | OCR/原件不可读或材料被禁止访问，非本人资格错误 | applicant/受权 reviewer 处理 |
| `EVIDENCE_CONFLICT` | 人名、编号、日期、回执或版本相互矛盾 | reviewer 复核，必要时校方核证 |
| `POLICY_UNCONFIRMED` | 版本、当期适用、内部权限或阈值未确认 | teacher/授权校方责任人；禁止自动合规结论 |

## 11 输出合同、追溯与状态不变量

每份结果包含：`caseId/templateId/version/scenario/policyEvidenceStatus`、`checkKey=sectionId:criterionId`、匹配的字段/材料槽及真实 `DocumentVersion`、检查执行类型、事实结论/缺失/差异/置信限制、原件位置、建议补件、下一角色、受信操作记录引用、`planId/fingerprint`。不同阶段是同一案卷上的不同审查运行，不从 R ID 伪造校本 PolicyVersion。

1. **预审报告**：逐项列出已核事实、未核政策、尚未读取的材料、可能的例外、下一办理人，不自动作出资格/级别结论。
2. **补件清单**：必须精确到 `Mxxx` 和某个情形，注明“初审后可补”还是“有权决定前必须核实”；M011/M021/M025/M030 的后置回执不能当作进站初次提交的前置条件。
3. **考核与出站核验单**：分别陈列导师意见、专家书面结果、设站单位真实决定、系统受信回执；缺任一层不声称办结。
4. **复核/申诉记录**：提交者、申请理由、引用旧结果和新事实版本单列。撤回意向并不自动撤销学校已经形成的决定。
5. **版本性**：材料替换、政策变更、模板改变、争议开启均使旧 Run 不可作为当前正式决定依据；受信 Main 负责 CAS/最终决定和 Outbox，而非模板直接写回。

## 12 异常、保密与人工兜底

- 身份/签发权限未核：标记 `POLICY_UNCONFIRMED`，停止**自动正式决定**而非停止已授权范围内的事实预审。
- 初审缺少少量材料：已具备的部分仍继续核验；材料槽精确列明后置补件，决定前复核，避免一缺即“提交失败”。
- 同一人员多个阶段或不同计划：按实际主情形分次记录，不把年度考核自动升级为中期或出站考核。
- 证据互斥、法规版本冲突、超期疑点：保存原始版本与冲突源，要求有权人核准；不能凭模型语义输出“违法”“符合”。
- 退站、不合格、涉健康、纪律、出入境、科研诚信：默认高风险人工路径，只记录最小必要状态；一般联网模型不得自动接收全部敏感附件。
- 涉密科研、未公开技术、军工合作或限制公开文书：不得上传一般云端语义审核；按学校授权隔离流程处理，只登记脱敏索引与“未获读取授权”。
- 本地身份/teacher 仅是软件角色，绝不推定已获学校博管办、学院、流动站、学术委员会或省级部门签发权限；不设置学校远端回写端点。
