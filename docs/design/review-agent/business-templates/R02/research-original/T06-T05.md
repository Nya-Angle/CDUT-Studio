## 01 唯一审核目的、申请人和负责机构

### 1.1 决定对象

1. **事实对象**：在指定统计期内，导师与被指导研究生的真实、有效、带时间范围的指导关系，以及个人培养计划指导、培养环节参与、学术规范把关、研究生培养质量、学生评价、指导精力投入等可追溯证据 [SRC-001：第 4、5、15、17–19 条]。
2. **工作量对象**：学校/培养单位确有依据的指导数量、分担比例、折算单位与有效期间。**现阶段没有已核实的研究生导师工作量折算公式或硬阈值**；仅可记录原始数量与证据，不能计算校定标准学时或绩效金额。
3. **正式决定**：校本第 17 条的“导师岗位年度考核”由导师招生学科（专业学位类别）所在**培养单位**作出，报党委研究生工作部、研究生院**备案**；备案与考核不是同一个决定动作 [SRC-001]。若具体学院另有岗位工作量认定决定，应待该学院现行办法与权限文书确认后挂接，不直接从岗位管理办法推定。
4. **不是本决定**：导师基本任职资格、年度招生资格、招生名额、导师停招/退出、研究生学籍或学位资格、任课教学工作量、奖金绩效核发。

## 02 适用、排除与邻接模板路由

### 2.1 适用原则

- 适用：成都理工大学在某年度/考核期间内，对**研究生**导师指导关系和履职证据进行事实核验，作为培养单位有效年度考核的依据 [SRC-001]；后续取得校本依据后可核实际“指导工作量”折算。
- 适用但需分情形：博导/硕导、学术型/专业学位、校内/行业导师、主导师/导师组、年度中途换导师、停招但仍指导在籍生、导师离校/调离/无法履职、跨学院联合培养。并不意味着各类共享相同工作量公式 [SRC-001：第 8、10、15、18、19 条]。
- 排除：本科生学业导师，包括环境与土木工程学院优秀本科生导师制。该院 2025 年办法第 6 条的“每生每学年 4 个教学标准学时”**只能用于其优秀本科生，严禁迁移到研究生导师** [SRC-007]。
- 排除：研究生本人培养环节审核或论文/学位决定；本模板最多引用有权系统形成的完成状态或质量结论，不复做学生端的实质性裁量。

### 5.2 产品可信数据契约（设计要求，非学校原始规章）

- **可信 Actor**：身份由 Main/Host 经认证会话、单位归属、权限角色和受控委托关系解析；Renderer 传入的 `teacherId`、`reviewerId`、`role`、`approved=true`、签章图片一律不构成信任依据。记录 `actorId`、有效角色、实际操作、时间、认证来源及委托链。
- **可信 Case/Run**：唯一案卷 `CaseAggregate` 保存提交材料、每次事实核验快照、材料版本、来源记录和正式外部决定引用；Run 必须为实际执行的有来源审查，不得把旧 `run@rev` 或人造 UI 状态伪装正式考核运行。
- **权威主键候选（字段待第 2 轮确认）**：导师学校人员唯一标识、导师岗位及聘任类别、招生学科/培养单位、研究生学号、研究生类型、师生关系开始/结束日、变更批准事件、考核年度、业务口径版本、校本政策版本。未明确数据持有系统前禁止假定这些字段均可读取。
- **来源优先顺序（暂定）**：学校正式导师/学籍/导学关系及培养质量系统记录和有效决定 ＞ 培养单位签认原件 ＞ 本人申报及导入文档 ＞ AI 从材料提取候选。发生矛盾则 `CONFLICT` 待校方核，不执行“最后上传覆盖学校值”。
- **最小化与保密**：学生名单与评价意见涉及个人信息；健康、纪律及匿名学生评价原始数据还可能触及更高敏感等级，具体依法分类 [SRC-014 第5–9、28–30条]。须确定合法处理基础、目的和最小字段、限制审阅/导出、保留周期与安全措施；**不得因资料可公开或技术可连接就默认获得对真实个人数据的访问授权**。
- **决定写入约束**：`PASS_FACT` 仅代表某一事实核对成功；如无正式带权签发/备案的学校事件，不能置为“考核合格/工作量批准/绩效可发”；人工作出的裁量单列 `NEEDS_HUMAN_DECISION`，不能由系统默认超时自动批准。
- **更新与冲突**：名单变化、导师变更、学籍更新应绑定数据源版本/事件时间，必要时仅重核受影响学生及期间；撤销/更正学校既有决定须经原有权程序，不用材料替换掩盖历史。

### 5.3 本轮必须保留的权限未知项

当期负责院系的组织权限、校内代表签字人、导师委托代办是否允许、行业导师是否可提交、在多学院任教导师的唯一归口、学位评定分委员会是否参与具体院级年度考核、对既有结论的复核机关及期限，均**不能由源代码或通用流程推定**。尚未取得当期院级制度和部门确认，仅保留角色占位和人工停机点。

### 5.5 身份/材料版本/决定链的硬边界

1. **人员匹配**：F008 与 F014 的学校唯一标识是候选主键；姓名 F009/F015 仅作复核，不允许同名自动合并。无工号、无学号、同名、改名或 OCR 识别出错时进入 CONFLICT 或 NEEDS_MATERIAL，不在数据中生成“新身份”。
2. **双时间轴**：F003 统计期、F011 任职期、F018 学籍状态期、F020/F021 导学关系起止、M016 变更批准生效日必须分别保留。附件“填写日期”不等于有权决定“生效日期”。
3. **关系唯一性是核验目标而非先验规则**：同一学生可存在校内主导师、行业导师、导师团队成员 [SRC-001 第19条；SRC-010]；因此不强制“一生只能有一名导师”，只禁止同一真实指导贡献在同一核算口径下无依据双重计量。
4. **双重权威**：任职资格/停招/年度招生资格来自相邻 T06 权威决定；研究生培养/学籍/学位结论来自对应 S/校内学籍权威系统；本模板只保存引用 ID、签发主体、版本和生效期，不复制写入它们的业务真值。
5. **主从与失效传播**：主记录是有权决定/可信系统事件；扫描件、Excel 和人工说明为从证据。文件替换生成新材料版本，旧版不可物理抹除，所有依赖旧版的事实预审标记 STALE 并仅重审受影响导师、学生、期间。学校已签发 M021/M022 仍保持原效力，直到有权更正。
6. **证据来源失联**：如果学校系统不可访问，记录最后可验证来源、采集时间、版本和 SOURCE_UNAVAILABLE；不自动回退为“申请人上传有效”，除非有权机构正式认证替代原件。
7. **隐私访问级别**：P0 公开制度，P1 校内业务/导师工作信息，P2 学生身份/学籍/师生关系，P3 督导评价、学生匿名评价及涉及个人健康纪律的高敏信息。P3 默认最小可见，原文和导出须校方具体权限审批。
8. **人工决定区**：F032 指向经核实现行的学院折算口径才可计算 F033；口径不存在、失效或不适用时 F033 保持空并写 POLICY_UNCONFIRMED，不能用本科或其他学院标准填数。

### 7.2 材料替代、真实性与阶段门禁

1. **来源优先**：对 M003、M005、M006、M010、M014、M016、M018、M021、M022、M028，首先请求有权记录；如没有技术接口，允许权责机构现场核验或出具有权限的书面证明，**不**把个人 Excel 截图升级为权威。
2. **申请人减负**：普通年度 P1 所需学籍与导学关系应尽量直接由学校查取。让导师重复上传全体学生身份证、学籍证明、论文全文缺乏必要性且增加隐私风险；材料槽只索取核验所需最小范围。
3. **阶段归属**：M011–M013 是 P3 评价资料，M021 是 P4 决定，M022 是 P5 备案，M027 是 P6 复核决定；任何新案 P0–P2 要求这些“先交”均属流程错误。
4. **替换处理**：M026 的新版本必须声明被替换 M、受影响 F、导师/学生/时间范围；旧版本预审失效后重新核对，而有权签发的 M021/M022 不因材料换版自动消失。
5. **照片/扫描件**：以页码、表格行、签章区的坐标定位并保存原文件哈希。OCR 无法读取的关键身份/日期进入 UNREADABLE；不能靠模型补字猜姓名学号或伪造落款。
6. **数据滞后**：同一学生的注册状态和导师关系可由不同机构记录，版本时间不同不能自动择新；需区分“来源时间更新”和“变更决定正式生效”。冲突反馈培养单位，停自动计量。

### 7.3 校本实际表单与本事项的差异

- SRC-005 包含学生学期注册、学院注册统计和纸质签章要求，证明学校在**学籍事项**有系统与汇总表；它不是导师年度工作量报表。
- SRC-010 学位点年度报告披露双导师分工与院级年度考核实践，但未给出导师个人申报表、考核评分表或可复制的计量标准。
- SRC-007 有本科优秀生科研训练任务书和导师联系记录表；对象为本科生，绝不可把这两张表设成 T06-T05 的必交材料。

## 08 审核规则逐条清单

### 8.1 规则语义与执行前置

- **本节是审阅型规则合同，不是学校已部署的自动规则。** R001–R026 不分裂为多个模板，定位在本事项的事实核验、来源验证、结论引用与程序门禁。任意 R 的 PASS_FACT 仅证明所指对象的一项事实；学校年度考核仍依 SRC-001 第17条由有权培养单位形成。R004、R009、R021 仅**核验并引用** T06 或 S 端已有有权决定，不代签该决定。
- T/F/U 专指**触发条件** True/False/Unknown，与结果码正交。只有“有可信事实足以证明条件不适用”时才可 NOT_APPLICABLE；适用性未明是 U，不得伪装为 F。每行“结果”描述通过事实核验时的首选码和失败码；校方源未开放走 SOURCE_UNAVAILABLE，文件无法读取走 UNREADABLE，有反证走 CONFLICT，应提交的私有事实材料确实缺走 NEEDS_MATERIAL，制度版本/权限不明走 POLICY_UNCONFIRMED 或 NEEDS_HUMAN_DECISION。
- 对照时固定查询日期 F040、年度窗口 F002/F003、身份及任职 F008/F011、导学关系 F014/F019–F021 的主键和生效区间；“上传时间最近”不代表法定效力最新。对所有 R 记录证据来源系统/记录号、文件版、页码/行格、采集时点、被审导师/学生/期间及可用 SRC，保存失败反证。原始权威记录 ＞ 校方正式签认的替代凭据 ＞ 个人陈述 ＞ OCR/模型候选。
- 后续办理角色是**任务建议接收者**，不是系统授予校内身份；只能由 Main 认证且经过实际校内授权者处理。与其他单位冲突时，转其有权机关读原决定，不能另写决定。各行列示的校本依据仅支撑其政策中真实规定的目的；原文未规定的折算权重、截止日、申诉天数一律空值或人工核定。

## 10 结果状态、问题与待办输出契约

### 10.1 八种互斥、单一事实结果

每个（caseId, realRunId, ruleId, targetKey, 统计区间, evidenceVersion）**只有一个当前 resultCode**。一个导师案卷可有很多逐生规则结果；不允许把其中任何一条 PASS_FACT 上卷为“全案已批准”。以下八态是**事实预审输出**，不是学校正式行政决定类别。

| 唯一 resultCode | 精确定义与可用前提 | 排除条件、后续任务 |
| --- | --- | --- |
| **PASS_FACT** | 触发为真，所审事实/引用来自可验证适用权威源，材料可读、标识/期间一致、比较方法可重复；若 R019，只代表按**已核现行口径**得出的候选计算 | 不能等同“材料齐全”“导师履职优秀”“年度考核合格”“工作量获批”“已备案”；对 R021 只代表已存在的正式决定**被核验可引用** |
| **NOT_APPLICABLE** | 有证据证明触发为假、子情形不适用或该后续阶段尚未进入，且不是对关键事实的沉默 | 不用来掩盖“存在触发可能但无法取得材料”的 U 状态；未到 P4 的 M021 是尚未产生而非缺件 |
| **NEEDS_MATERIAL** | 规则当前确实需要某项**由提交方/可控材料持有方提供**的证明，但尚未提供，且不是权威源暂不可用 | 必须指明当前阶段、M 编号、合法替代、补交人；学校可读取者不得无理由要求导师重复上传 |
| **CONFLICT** | 两个或以上可定位来源对同一身份、期间、关系、事实或版本存在不可同时成立的陈述，或操作者身份与授权不一致 | 同时保留正反证据，不自动按上传新旧、OCR 置信度或“多数材料”裁断 |
| **UNREADABLE** | 文件、图像、页码、表格或受保护内容虽存在，但关键姓名、学号、日期、签发内容无法可靠读取 | 指向问题页/单元格和同权威替代渠道；禁止模型猜补；可读字段仍保留独立结果 |
| **SOURCE_UNAVAILABLE** | 必须由校方有权主系统、签发/备案机构核真的来源当前失联、无权限获取或无法验证其真实性 | 留来源名称、请求时点、失败类型、最后已核版本；个人截图不是自动授权的降级替代 |
| **POLICY_UNCONFIRMED** | 适用院级/校级规则、有效期、计量单位、分担、时限或复核程序缺乏可验证的**当期校本**依据 | 不写数字/阈值/最后期限，不借 SRC-007 本科标准，不从 SRC-003/004/009 的不确定部分强推 |
| **NEEDS_HUMAN_DECISION** | 事实已足以提交有权机构裁量，或者签发/复核/归口/撤回的权限与结论必须由有权真人确认 | 不由 LLM、OCR、Renderer 或默认倒计时更改学校决定，不暗示“等待即自动批准” |

**互斥执行顺序**：先判断触发真/假/未知和所处阶段；真时分别检查权威来源是否可验证、原件可读、材料是否实质缺失、两个来源是否矛盾、当期政策是否确定、是否存在不可自动作出的裁量。对于同一 R/对象有多个异常，产生**多个 issue**，但当前 resultCode 只能取一个最先阻断该核验对象的主状态，其他异常挂为 secondaryFindings；每条 issue 都保留自己的异常码和责任人。只要不能把完整可信证据链走通，就绝不 PASS_FACT。冻结同一实际运行的输入版本；不同运行不能互相覆盖历史结论。

## 11 补件、撤回、版本更新、复核与人工决定

### 11.1 案卷程序状态与学校决定状态分离

案卷的**产品办理状态**不等于学校行政行为。下列程序可供 V3 Case 工作区展示，但“受理”“撤回生效”“复核批准”的法定含义只能在拿到当期学校流程与有权事件后赋予。

| 进入前状态 → 请求事件 | 可记录的产品状态及前置 | 生成证据/下一角色 | 不得推定 |
| --- | --- | --- | --- |
| DRAFT → 可信主体保存或修改 | DRAFT；F001/F004/F040 与每版材料关联 | 本人或有权限代办；R002，保存草稿历史 | 未提交不算学校已受理 |
| DRAFT → 提交当前自评 | SUBMITTED_FOR_FACT_REVIEW；R001/R002，M007 仅在 P2 到达时要求 | 受理经办核 M001/M003–M007，指派 R001–R018 | 无 M021 不应把 P4 决定标成缺件 |
| SUBMITTED_FOR_FACT_REVIEW → 事实检查 | FACT_CHECKING / WAITING_MATERIAL / WAITING_SOURCE / WAITING_POLICY / WAITING_HUMAN | Issue/Task 与 R、M、F、版本一一关联，材料 Owner 处理 | 八种事实结果并非互斥全案状态 |

### 11.2 版本更新、影响边与定向重审

1. 记录 M、F 的原始版本 F040，包括 SHA-256/源记录版本、校方签认时间、对象（导师/学生/期间）、来源定位；新增附件创建新 evidenceId，不覆盖旧版。
2. 计算变更集：新旧版新增/删除/变化的 F、涉事学生/导师 ID、导学角色、时间交集；仅将**依赖这些字段的 Check**标记 STALE。OCR 不可读不能自动判事实已改变，应先重取可识别来源。
3. 从“材料 M → 字段 F → 规则 R → 下游候选 R”建立版本依赖图。若学生名单 M006 更新，最直接受影响 R008/R009/R011/R012/R018；其人数依赖传递至 R019；原 R021/M021 是外部有权结论，**只触发 R023/R026 的人工更正通知**，不被新 Run 重签。
4. 在新 realRunId 中只计算受影响 Check，并把未受影响且证据快照相同的 Check 引用为“沿用的可验证事实”；旧 Run 与旧证据/对比保留。不得把增量执行假装为旧 Run 原地变更。
5. 多字段争议优先维护逐生/逐导师/期间粒度；仅在政策要求跨期全量合计而变更影响全体时才重算该汇总 R018/R019，不以“保守”名义每次全案重审。
6. 异议后若 M027 形成新有权决定，生成新的 OfficialDecisionRef 和备案待办，并对 F039 的真实下游引用发**人工影响提示**。下游 T06/S/T/绩效的变更依其各自原授权，禁止双写。

### 13.2 六类闭环必须成立的核对断言

1. **事实成功≠决定成功**：S01 事实 R 可 PASS_FACT，但年度考核仍需 P3 综合评价、P4 培养单位有权结论 M021；P5 备案 M022 另核。
2. **缺件与来源失联分开**：S02 是应提交的自评缺失，S05 是校方权威系统不可得；分别落 NEEDS_MATERIAL 和 SOURCE_UNAVAILABLE，不凭个人自报代替学校源。
3. **冲突与不可读分开**：S03 有两组可读但矛盾的记录，S04 关键位无法识别；分别 CONFLICT 和 UNREADABLE，不由模型“猜一致”。
4. **更新只影响相应 R/目标**：S06 旧事实 Check STALE 并生成新 Run；已有正式学校 M021 不失效，直至有权更正。
5. **撤回与复核有权限门禁**：S07/S08 区分草稿取消、正式撤回请求、异议请求、正式复核决定 M027；无校本授权时必须人工接手。
6. **高风险跨域不能借权限**：S09–S19 确认本科/外校政策、招生名额、学籍状态、导师资格、授课工作量、匿名评价及签发行为不会被本模板新造、泄露或回写。

**演练结果性质**：上述 19 项均是基于当前公开政策及规则合同的**合成纸面推演**，尚未在真实校内记录、签发机关、接口或客户端上运行；不能写为实机验收通过。S16–S19 是第四轮针对本校 2026 项目、外校误用、回溯有效期和敏感数据泄露的敌意重放。

### 14.2 覆盖、去重与异常阻断结论

- **规则/材料编号**：R001–R026、F001–F040、M001–M028、SRC-001–SRC-015 连续；26/26 规则含 SRC、F、M，26/26 可追至 P0–P6 某已定义阶段；28/28 槽可追至真实业务或后续程序的至少一个 R。结构检查与校本实测是两个不同结论。
- **八态与版本**：八种 resultCode 不相互取代；NOT_YET_CREATED 和 STALE 是时间/版本属性而非第九种事实结果。补正只影响依赖旧证据的 R，不覆盖旧 Run 或 M021/M022 正式结论。
- **跨模板不双写**：T06-T01/T02/T03/T04、S08、T05-T08、T02-T05/T07 和 G50 分别拥有自己的原决定或通用技术契约。T06-T05 仅消费可信只读引用；现阶段取得了 G50 及 R02 三份原件的**目录级**证据，未审完整 G50 workspace 的业务语义，不夸大其验收。
- **不能自动裁定**：当期考核任务/院级公式、行业导师分担、正式签发权限、申诉撤回/追溯时限均待校方；规则输出 POLICY_UNCONFIRMED 或 NEEDS_HUMAN_DECISION，而非凭 AI 生成“审批通过”。
- **实机状态**：19 个为规则合成纸面演练，未取得真实申报/审批样本，未运行 CI、客户端或学校系统；本轮不声称正式验收。
