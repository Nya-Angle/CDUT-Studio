## 01｜唯一目的、申请权与决定权

1. **自然人发起**：本校在职专业技术人员可按适用批次向所属教学科研单位递交申请意向；校级教学名师历史办法规定个人申报，省级带头人终端制度**不受理个人直接向省申报**。外部柔性专家的“天府学者”由**在川设岗单位组织推荐**，专家同意和签约意向不等于其可绕过设岗单位直接申报（SRC-001/002/004/005）。
2. **组织发起**：学院/实验室/归口教学科研单位核验资格与业绩，依批次组织会议、专家意见、党委推荐及材料移交；人事处/党委教师工作部为人才计划的校内归口，校级教学名师历史流程由教务处承担规定性条件复核；若有当期校文不同，以当期有效签发文件为准。
3. **唯一业务决定分层**：`UNIT_RECOMMENDATION`（单位推荐）→ `SCHOOL_RECOMMENDATION_DECISION`（学校审定是否上报）→ `EXTERNAL_AWARD_DECISION`（省级/国家级有权机关选拔授予）→ `APPOINTMENT_OR_MANAGEMENT`（签约、考核、退出）。任何上游阶段`PASS_FACT`均不可提升为后一阶段的批准。
4. 只对**可验证事实**给出结果码；学术水平、师德审查意见、破格合理性、同业评议、限额择优、异议实质处理均明确转有权组织**人工决定**。

## 03｜情形与生命周期

**子类型**：`SC_LEADER`四川省学术技术带头人、`SC_RESERVE`后备人选、`TF_SCHOLAR`天府学者设岗选聘、`CDUT_TEACHING_MASTER`校级教学名师、`SC_TEACHING_MASTER`省级教学名师、`OTHER_TALENT_HONOR`其他有当期正式授权通知的专家/人才荣誉。不得用通用兜底猜测不存在的评选计划。

**阶段**（按事件而非单一“已通过”状态） ：

`INTAKE`个人/单位申报意向 → `BATCH_BOUND`绑定当期通知和版本 → `UNIT_DRAFT`单位预审及组织评议 → `SCHOOL_REVIEW`人事/教务事实复核 → `SCHOOL_DECISION`校内审定/公示与异议处理 → `EXTERNAL_SUBMISSION`按授权向上级平台及纸本报送 → `EXTERNAL_DECISION`外部终审/正式名单 → `POST_AWARD`签约、管理期/聘期考核、变更与退出。

并发支线：`CORRECTION_REQUESTED`（补件）不改变批准状态；`WITHDRAWAL_REQUESTED`（申请撤回）只登记、等待权限方确认；`OBJECTION_RECORDED`/`REVIEW_REQUESTED`保存原决定快照和新证据，移交有权复核；`SUPERSEDED`材料重传生成新版本并按依赖图重审，旧决定仍以原时点版本可追溯。逾期更正、系统锁定后的改报与涉密渠道均不得自动覆盖。

**分批要点**：

- `SC_LEADER/SC_RESERVE/2025-16`：单位可推荐不限名额但学校受教育厅限额约束；教学科研单位先交评审材料、学校遴选后分配系统账号；系统截止2025-06-16，电子提交后不可更改；脱密、系统打印及纸质版分段适用（SRC-001/006）。
- `TF_SCHOLAR/2025-6`：岗位设置与拟聘专家同步，单位推荐限额和初步意向；先单位党委名义推荐、党委教师工作部复核、学校审定，再报上级；获批后合同备案与聘期考核是**后来才发生**的事件（SRC-002/005/007）。
- `TF_SCHOLAR/2026-7`：2026批次存在（SRC-008/012），**不可复用**2025-6校内名额3、截止8月8日、旧推荐表；缺CDUT该批通知必须`POLICY_UNCONFIRMED`。
- `CDUT_TEACHING_MASTER`：2012旧制要求由优秀教师人选选拔，校务会审定；历史具体学时、职级、评选比例、年度时窗与“最近3届”省级候选限制均默认**禁用**，直到教务处确认现行效力（SRC-003/010）。
- `OTHER_TALENT_HONOR`：当期省部级或国家通知缺失时仅可建登记案与列材料清单草案，不可启动实质资格裁定。

1. 先执行R001–006的**批次和权限闸门**。若F008/F009无法绑定有效本批原文，仍可收件与列证据清单，但不得执行其下硬阈值；输出`POLICY_UNCONFIRMED`并展示研究可知的历史/跨校提示。

### 09.3 三值事实逻辑、停止条件和异常

- `true`代表**对应原子事实已被权威证据证明**，如“纸电版相同”或“单位函存在”；不得因其他规则也通过而提升为候选获批。`false`在有可读证据互斥时给`CONFLICT`，在明确无资质而当期政策有效时可标`NEEDS_HUMAN_DECISION`供有权者作否决决定，不由系统直接处分。
- `unknown`先判：缺适用材料→`NEEDS_MATERIAL`；材料坏/无可读页→`UNREADABLE`；签发机关原文无法取得→`SOURCE_UNAVAILABLE`；时效/例外/现行性不可确定→`POLICY_UNCONFIRMED`；学术/政治/破格等实质裁量→`NEEDS_HUMAN_DECISION`。
- 严重错误路由、未绑定可信身份、涉密误入普通渠道时，**阻止报送动作**但不删除案卷；保留问题与转交。附件哈希变化必须拆分旧结果快照、新结果快照。
- 系统不直接驱动“授予、取消、撤回完成、批准申诉”事件。外部/校内的最终决定仅能由受信签发方经后端提交。不同文书版本按生效日、批次、适用人群判定，均不符合时标`POLICY_UNCONFIRMED`。

## 11｜补件、撤回、决定、复核与局部重审事件闭环

事件主键：`event_id, case_id, event_type, actor_id(server_verified), role_scope, object_id, slot_id, source_version, payload_hash, occurred_at, request_id, acknowledged_by, prev_event_hash`。材料提交采用不可变版本；每个审核Run冻结`plan_id + fingerprint + rule×target + source_version`，签发结论只认当前案卷的有权Decision事件。归口人工决定不能被客户端显示状态写回替代。

1. **补件**：`MATERIAL_REQUESTED`明确R、M、F和页/版本→材料持有人提交`MATERIAL_REPLACED`→生成新hash与可信提交人→重跑该槽受影响的R；与其无关规则沿用之前可重放结论，需保留原版本。
2. **撤回申请**：`WITHDRAWAL_REQUESTED`含请求者身份与原因、所处阶段和原决定指针→R046仅核收件事实→归口确定该阶段受理机构与期限→机构签`WITHDRAWAL_ACCEPTED/REJECTED`。收到请求不删除已上报材料，也不替外部撤回。
3. **学校决定**：审核事实包、单位意见、专家组评议形成可审阅提案→校授权机构以M021签`SCHOOL_DECIDED`→按本批要求公示、处置异议→向上级报送。没有M021时展示“待学校决定”，不是“审核拒绝”。
4. **外部决定**：有权机关签发M030→`EXTERNAL_AWARD_RECORDED`，校内只消费；需TF合同时触发M031以后义务。学校推荐了但上级未公布，仍显示“外部决定待定”。
5. **异议和复核**：`OBJECTION_SUBMITTED/REVIEW_REQUESTED`登记申请事项、原决定、证据和日期→`REVIEW_ACCEPTED/DECLINED`由真实受理机关作出→`REVIEW_DECIDED`附有权文书。因未核CDUT具体异议/复核期限，任何“时限内/超期”判断均先`POLICY_UNCONFIRMED`，不得自动拒收。
6. **报送后更正**：若2025-16平台已锁定，保留提交版与纸本，创建变更请求并等待主管机关允许；未获正式许可不能重新覆盖F039/M023。
7. **管理期**：TF新入选人员按SRC-005从被批准次月起算三年，旧聘期按2020旧制过渡；SC带头人及后备各按SRC-004六年记录。年度考核、主动退出、劝退、自然退出、取消资格和资金回收均需主管机关文书，不自动执行。

### 14.3 可交接性、变更请求和硬边界

**研究交接可用**：主体、阶段、证据账、字段/材料/规则、异常、局部重审与反例具备可审阅设计，允许按本稿实现**禁自动批准**的草案引擎与合成测试。**不得声明**：学校已授权、2026本校批次现行参数已取得、2025附件已逐字段下载、已有真实人事身份接口、ZIP旧主稿已继承、任何实机端到端通过。

待集成变更请求：

1. `CR-01` 批次政策注册器按`program/batch/issuer/valid_from/valid_to/document_hash`装载；未核现行性不启用硬阈值，特别隔离教学名师2012规则。
2. `CR-02` 申请草稿、单位推荐、学校审定、外部决定、聘期管理采用独立可信事件；Case/Run/Decision仅后端授权主体写入，不相信Renderer actor。
3. `CR-03` 材料按人/设岗单位/批次/槽/版本映射，结果绑定`rule×target×sourceVersion`，自动给出重传后的最小重审集合。
4. `CR-04` 2025带头人“两段材料”（校评Word+扫描PDF、正式系统打印+纸本）分流，涉密禁普通通道，天府意向书不提前要求正式合同。
5. `CR-05` 申请撤回、逾期更正、异议/复核仅登记请求并派有权部门，未签决定前不得撤销、改判或宣称已获称号。
6. `CR-06` 真正业务投产前需学校SSO/OA/公文签发、保密和外部接口授权验证；本次研究稿不实现客户端源码。

**结论**：`authoring_status=RESEARCH_HANDOFF_READY`；`policy_status=PARTIALLY_VERIFIED`；`school_approved=false`。研究可交接与政策待核是两条独立状态，后者限制自动裁定，但不阻断结构性交付。
