## 01 唯一目的、主体和权限

本模板针对**一名研究生、一次中期考核尝试及其后续整改、重考、复议**，核查培养计划执行、开题到中期节点、课程与实践/学术活动、论文与科研进展、导师意见、评审程序、结果及后续处理的证据一致性。[SRC-001 第40–49条] 学生提交事实材料；导师审查并建议；培养单位确定组织时间与开展评审；有权评审小组人工给出“优秀/良好/合格/不合格”，培养单位办理首级复议，研究生院组织第二级专家复议。导师的建议不是评审等级，学院对学籍分流的建议更不是学校学籍决定。[SRC-001 第41、44–49条][SRC-002]

创建者可为学生本人或经授权的培养单位办事人员；实际发起权限、代理提交与电子签名需服务端校验。模板不创造独立行政许可，不自动产生学校结果。

## 02 适用范围、排除及转交

适用于学术/专业硕士、博士、直博与非直博，以及工程类专业博士不同成果路径的**中期**。国境外访问远程考核、提前毕业间隔例外、首次评审、等级后的整改、至少三个月后的重考、两级复议是同一 ID 的子情形。[SRC-001][SRC-003]

| 邻项 | 本模板只读/转交边界 |
|---|---|
| S08-T01 导师选择变更 | 消费有效导师身份；导师资格/变更不在此批准。教师导师资格另归 T06 相应业务。 |
| S08-T02 培养计划与课程安排 | 消费生效计划、成绩和变更决定；不批准替代课程。 |
| S08-T03 开题 | 消费有效开题等级、日期与重大题目变更后的重新开题决定。 |
| S08-T05 科研成果及学位申请成果要求认定 | 中期检查成果进展证据；不判成果是否满足学位申请要求。 |
| S08-T06 预审/预答辩/送审，S08-T07 正式答辩，S08-T08 学位决定 | 只传递中期通过的可信记录，不提前审后续阶段。 |
| S08-T09 联合培养/培养单位变更 | 消费已生效培养归属；访问学习考核方式按本模板第46条处理。 |
| S01-T08 修业年限，其他学籍事项 | 不替学校批准延期毕业、分流或退学。 |
| G06 成果登记、权属、伦理和发表前合规 | 只核材料存在和对应培养进展；权属、伦理、成果真实性争议转 G06 的对应子模板。 |
| G50 其余通用事项 | 身份/证明/用印等只消费有权业务的结论，不复制审批。 |

博士综合考核属于 [SRC-001 第二章] 独立培养环节，不得把其结果当中期；专业实践考核也不是中期等级。若路由对象是开题、送审或学位申请，直接移交相应 ID，并保留原案卷关联，不改本 ID。

## 03 情形、节点与生命周期

| 情形/对象 | 触发与前置 | 申请窗口/路径 | 人工决定及撤回/复核 |
|---|---|---|---|
| 硕士常规（学术/专业） | 开题已通过；通常半年后中期；非直博最迟第六学期末；看生效培养计划 | 培养单位安排具体日程，个人准备考核表 | 导师建议→学院组织小组等级→发布；发布前撤回参照学院受理规则 |
| 博士非直博 | 开题通过通常一年后；第六学期末完成中期 | 同上 | 同上；博士综合考核不可替代 |
| 直博 | 开题通过通常一年后；第七学期末完成 | 同上 | 同上 |
| 工程类专业博士 | 中期研究进度或实践成果实施进展；专业细则另适用 | 同一中期案卷，成果路径作为条件 | 只审中期，成果展示鉴定归后续阶段 [SRC-003] |
| 国境外访问 | 因在外无法到校按期 | 本人书面申请，导师及培养单位审核同意后远程或通讯评议 | 无同意不得默认远程合法 [SRC-001 第46条] |
| 提前毕业间隔例外 | 按期完成培养环节、进展顺利并具备提前毕业条件 | 本人申请→导师同意→学院审核→研究生院备案 | 具体可放宽幅度人工确认 [SRC-001 第50条] |
| 首次等级良好/优秀 | 已有可信等级记录 | 形成下一步修改计划 | 导师确认，不重判等级 [SRC-001 第48条] |
| 首次等级合格 | 已有可信等级 | 按专家建议形成整改报告 | 导师确认；学院额外复查程序待证 |
| 首次不合格 | 已有可信首次结果 | 间隔至少三个月的第二次中期 | 第二次独立评审；两次未通过转有权分流程序，不自动退学 |
| 首级复议 | 结果发布起 15 日内 | 学生向培养单位申请 | 培养单位受理、复核并处理 |
| 二级复议 | 对首级复议决定有异议 | 书面向研究生院提出；具体时限未见明文 | 研究生院组织专家审核评判，不由 AI 更改等级 |

阶段状态建议：`REGISTERED→ELIGIBILITY_CHECK→STUDENT_MATERIALS→ADVISOR_REVIEW→COMMITTEE_REVIEW→RESULT_PUBLISHED→(PLAN_CONFIRM / RECTIFICATION / REEXAM / RECONSIDERATION)→ARCHIVED`。撤回、驳回退补、复议为带版本的事件，不擦除已有评审；未来才产生的意见不得在前一阶段报缺。

## 05 执行者、证据持有者与可信身份

学生持本人报告/书面申请；导师持评价和确认；培养单位持排期、评审原始记录、成绩发布、首级复议；研究生院持备案与二级复议；教务/研究生信息系统持学籍、计划、课程、开题和结果权威记录；合作单位可持专业实践或工程进展证明。可信级别优先为后端校验的校内记录、部门正式签发、可核外部机构签发、学生上传佐证、OCR/模型抽取。后两类不具有签批效力。

服务端必须校验主体、角色授权、有效培养单位、案卷与材料 owner、签发人及权限范围、批次、版本和来源；Renderer 自报 teacher/admin 字符串一概不可信。学号、成绩、政治品德评价、科研未公开信息、复议理由属于敏感资料，最小权限、遮蔽导出、审计访问；不得以其他人的成绩排名明细任意泄露。远程申请与决定不可由用户伪造的“已批准”字段确认。

## 09 复合情形与冲突解决

应用条件先以 F003 学段、F011 例外、F021 已签发等级、F024 考核次数判路由，再激活对应 M/R；未触发的材料不得催交。开题变更未获有效重开题结论，暂停时间线事实核验并转 S08-T03。工程博士成果路径如与普通论文材料不同，可由学院认可的实践成果进展记录替代论文进度佐证，但学位成果最终认定不在此做。[SRC-003]

政策优先级：有效校发新制度及适用过渡规定→已备案且不冲突的学院实施细则→当期学院安排→表单说明；2016历史通知不得覆盖2021办法。发现同级冲突时记 `POLICY_UNCONFIRMED`，由研院解释。材料冲突（学号、导师、日期、签发等级）记 `CONFLICT`，保留两版本和签发方，权威系统核实前不得任选其一。不同字段只针对其规则产生问题，不输出“一票否决”的混合总判。

## 10 八类结果、问题与待办合同

唯一事实状态：`PASS_FACT`（事实吻合）、`NOT_APPLICABLE`（触发假）、`NEEDS_MATERIAL`（应有材料未交）、`CONFLICT`（证据矛盾/归属错误）、`UNREADABLE`（存在但读取失败）、`SOURCE_UNAVAILABLE`（权威源不可取）、`POLICY_UNCONFIRMED`（制度/时限/适用未知）、`NEEDS_HUMAN_DECISION`（须有权人裁决）。每条规则每个目标版本只取其中一个，学校成绩另设 `official_grade`，不可映射成事实状态。

问题对象最小结构：`issue_id, case_id, attempt_id, rule_id, target_person_id, target_stage, field_ids[], material_slot_id, evidence_id, evidence_version, source_ids[], status, explanation, required_action, assigned_role, due_policy, resolved_by_event`。例如 `R017/M011` 导师意见缺失指向导师，不能并入 `R013/M007` 教务统计缺失；问题修复时留存旧问题历史。高风险决策输出始终标为“待授权机构确认”，不写“审核通过”代表学校签批。

## 11 事件、补件、撤回、复核、定向重审

事件序列：`CASE_OPENED`、`MATERIAL_ATTACHED`、`MATERIAL_SUPERSEDED`、`FACT_RECHECKED`、`ADVISOR_SIGNED`、`COMMITTEE_SIGNED`、`RESULT_PUBLISHED`、`RECTIFICATION_SUBMITTED`、`REEXAM_OPENED`、`APPEAL_FILED`、`APPEAL_DECIDED`、`WITHDRAWAL_REQUESTED`、`WITHDRAWAL_DECIDED`、`CASE_ARCHIVED`。每个事件记录 actor 的服务端身份、业务权限、时间、版本、目标和前序事件。只有签发源可新增正式决定事件；已有结果不得因学生重新上传而静默修改。

补件改 M009→只触发 R015 与依赖该报告的评审前汇总，已签发等级不自动重判；更换 M006→R011–R013，M003→R006–R009，M013→R020/R027，M019→R027–R029。跨阶段更改有影响则生成重新送有权人确认的待办。撤回申请在受理/评审/发布前后具有不同法律效果，未公开统一程序，均记录请求并由培养单位人工决定；不自动删除已签结论。复议保持原结果版本，待正式复议决定签发后产生新版本并注明替代关系。重考创建独立 `attempt_id`，不可把旧 run@rev 冒作新评审。

## 13 合成演练与专属高风险反例

1. **正例**：硕士开题有效且满足间隔，有当期考核表、进展、导师意见；R006/R007/R010/R015/R017 `PASS_FACT`，评审等级仍 `NEEDS_HUMAN_DECISION`。
2. **缺件**：初审未交 M009，R015 `NEEDS_MATERIAL`；尚未开评审，不要求 M012/013。
3. **冲突**：学生截图导师甲而服务端生效导师乙，R004 `CONFLICT`，学生材料不能改权威导师。
4. **不可读**：M005 有文件但扫描乱码，R010 `UNREADABLE`，不得说未上传。
5. **材料重传**：M009 v2 替代 v1，复审 R015；若等级已发布则生成导师/学院是否复议/更正的人工待办，不自动改分。
6. **撤回复议**：复议提交后申请撤回，R030 `NEEDS_HUMAN_DECISION`；保留提交和撤回事件，由有权单位定效力。
7. **专属：旧2016规则污染**：给出“基本合格”及一次不合格自动退学；R019 `CONFLICT`，按2021四档且转学籍程序，不执行旧通知。
8. **专属：博士综合考核冒充中期**：仅有博士综合考核“优秀”无中期评审，R019 缺权威中期记录，不能通过。
9. **专属：硕士末5%**：只给个人75分并推测末5%，R013 `SOURCE_UNAVAILABLE`，不准强制降等；应取包含同考选修者的正式统计。
10. **专属：远程未批准**：在境外自行视频答辩，缺导师/学院同意，R021 `NEEDS_HUMAN_DECISION`，不能标程序有效。
11. **专属：合格整改被错当重考**：正式等级合格只触发 M017/R024，不触发 M018/R025。
12. **专属：连续两次不合格**：R026 仅产生“学籍分流转办”，不生成退学决定；后续学籍结论从独立业务消费。
13. **专属：提前毕业例外**：学生仅有导师聊天同意，没有学院审核与研院备案，R022 不能按缩短间隔通过。
14. **专属：申诉发布日期未知**：学生申诉日期可核但发布时点无法核，R027 `SOURCE_UNAVAILABLE`，不得断言超过15日。

## 14 双向核查、开放问题及交接判断

编号连续：SRC-001–008（8），F001–F028（28），M001–M022（22），R001–R031（31）。每条 R 至少给出触发、F、M、SRC、核对目的和下一角色；除有意标记现行性未知者外不引用不存在编号。M 有对应 F/R；部分字段如 F027 是跨规则事件元数据。未来材料只在对应阶段触发，所有评分及审批落在有权角色。

尚待业务专家确认的事项见第12节；其中结果实际签发链、学院实施细则、现行性、成绩群体分位算法、撤回复议时限应在真实接线前优先核准。`CATALOG-CHANGE-REQUEST: NONE`，无证据支持拆分本 ID；若将来确定中期内存在另一独立法定目的，先查 R02 总账再申请变更。本稿满足**研究交接可用**，不表示实现可运行、校方政策完全证实、生产授权或行政签发。
