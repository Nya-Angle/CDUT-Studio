4. **审核会话后台化未实现。** 本轮只有修改建议；现有侧栏会话和普通聊天跳转保持当前行为，待按 27 号实施。
5. **真实业务质量与最终使用流程仍需验收。** 多模板真实模型成功审读、独立标准答案、未知/冲突/补件组合、长材料和中断恢复的持续运行需继续测试。已有单案历史模型实验不能外推全模板准确率。
6. **校方身份、多人权限和远端生效未接入。** 本地角色视图及审计标签不等于学校授权；SchoolPort/可信身份与结果回写需要学校接口和对应验收。
7. **原生安装包与完整跨平台验收未完成。** Linux 离线 dev 与 Ubuntu CI 不能证明 Windows/macOS 安装、运行时依赖、更新和长时间批次运行全部通过。
